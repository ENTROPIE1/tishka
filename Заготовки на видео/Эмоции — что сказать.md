# Что сказать, чтобы сменилось лицо

Эмоция держится на **отрезке** реплики: `[joy] … [/joy]`. Одиночная метка без закрытия стоит до конца фразы, не вспышкой.

Перед съёмкой: персонаж **Тишка**, голос включён.

| Что хотим | Сказать | Метки |
|---|---|---|
| Спокойно | «Который час?» | без меток |
| Радость, глаза-галочки | «Я сдал отчёт с первого раза» | `[joy]…[/joy]` |
| Восторг | «Нас взяли на первое место» | `[delight]…[/delight]` |
| Смех | «Расскажи ёжиный анекдот и посмейся» | `[giggle]…[/giggle]` |
| Злость | «Опять сорвали дедлайн, поворчи» | `[anger]…[/anger]` |
| Печаль | «Мне сегодня грустно, посочувствуй» | `[sadness]…[/sadness]` |
| Удивление | «Мне повысили зарплату в два раза» | `[surprise]…[/surprise]` |
| Растерянность | «Ничего не понимаю в этом письме» | `[confused]…[/confused]` |
| Скепсис | «Коллега говорит, успеем за час. Как думаешь?» | `[skeptic]…[/skeptic]` |
| Смущение | «Ты сегодня очень милый» | `[shy]…[/shy]` |
| Влюблён | «Ты мой любимый ёж» | `[love]…[/love]` |
| Сосредоточен | «Разбери ошибку по шагам, без шуток» | `[focus]…[/focus]` |
| Усталость | «Уже полночь, я еле сижу» | `[tired]…[/tired]` |
| Кивок | «Согласен? Кивни.» | `[nod]` |
| Нет | «Это плохая идея, покачай головой» | `[shake]` |
| Подмигивание | «Подмигни, если понял» | `[wink]` |
| Фырк | «Фыркни, если бесит бюрократия» | `[huff]` |

Короткие жесты (`nod`, `wink`, `huff`) можно без закрытия. Долгие чувства — парой.

Приветствие при появлении — выглядывает из-за края (`peek`) и шаг. Танец: «Станцуй» / метка `[dance]`. Наушники — когда микрофон выключен. Планшет — пока идут инструменты (MCP, сайт).
