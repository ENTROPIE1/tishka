# Служба синтеза поверх лаборатории голосов

HTTP-обёртка над настольной «лабораторией голосов» (Silero + `voice_window.py`),
под интерфейс Тишки: `GET /health` и `POST /tts`. Один файл на Python 3.11+,
только стандартная библиотека. Сама лаборатория лежит вне репозитория.

## Запуск

```
python tts_server.py --lab <каталог лаборатории> [--host 127.0.0.1] [--port 8179] [--voice ru_roman] [--speed 1.10] [--pitch 4.5]
```

- `--lab` — каталог, где лежит `voice_window.py`; добавляется в `sys.path`.
- `--host` — адрес прослушивания, по умолчанию только локальный `127.0.0.1`.
- `--port` — порт, по умолчанию `8179`.
- `--voice`, `--speed`, `--pitch` — значения по умолчанию для синтеза.

Нет каталога или файла `voice_window.py` — служба печатает причину и выходит
с кодом `2`. После старта голос прогревается в фоне: первый синтез грузит
модели (десятки секунд), дальше быстро.

## Проверка

Состояние (пока идёт прогрев — `503 {"status":"loading"}`, затем
`200 {"status":"ok", ...}`):

```
curl.exe http://127.0.0.1:8179/health
```

Синтез в файл `out.wav` (ответ `audio/wav`):

```
curl.exe -X POST http://127.0.0.1:8179/tts -H "Content-Type: application/json" -d "{\"text\":\"Привет, Тишка!\"}" --output out.wav
```

В теле можно перекрыть параметры запуска:

```
curl.exe -X POST http://127.0.0.1:8179/tts -H "Content-Type: application/json" -d "{\"text\":\"Привет!\",\"voice\":\"ru_ekaterina\",\"speed\":1.05,\"pitch\":2.5}" --output out.wav
```

## Рекомендованные наборы

| Голос | `voice` | `speed` | `pitch` |
|---|---|---|---|
| Роман | `ru_roman` | 1.10 | 4.5 |
| Екатерина | `ru_ekaterina` | 1.05 | 2.5 |

## Тесты

```
python -m unittest discover -s services/voice-lab -v
```

Тесты поднимают службу на свободном порту и используют поддельный
синтезатор, настоящая лаборатория не нужна.
