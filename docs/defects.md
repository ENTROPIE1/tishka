# Приёмка правок: статус дефектов

Обновлено: 4 октября 2026, 20:45. Файл обновляется при каждом слиянии исправления в `main`.

Статусы:

- **исправлено** — правка в `main`, проверки пройдены (типы, тесты, сборка). Нужна повторная проверка руками.
- **в работе** — исправление пишется или проходит приёмку, в `main` его ещё нет.
- **в очереди** — задача поставлена, ещё не начата.

Перед повторной проверкой: `git pull`, `npm install`, `npm run build:mcp`, `npm run dev`.

## Как отмечать проверку

В колонке «Проверено» у каждой строки стоит `[ ]`. После повторной проверки заменить на:

- `[x]` — проверено, работает;
- `[!]` — проверено, не работает или работает не так: коротко дописать в той же ячейке, что именно (`[!] после перезапуска снова растёт`), подробности — отдельным сообщением.

Затем `git add docs/defects.md`, `git commit -m "ФТ: отметки проверки"`, `git pull --rebase`, `git push`. Отмечать только строки со статусом «исправлено». Статус и остальные колонки не менять: их ведёт тот, кто вливает исправления.
