# 68. Ёж — основное место общения с первого запуска

## Что не так

После запуска открывается основное окно с чатом, ежа на экране нет. Человек пишет первое сообщение в чат основного окна — и только тогда появляется ёж со своей строкой ввода и тем же ответом. Получается два места для ввода и один и тот же ответ на экране дважды; основным человек считает то окно, куда написал первым.

## Что сделать

- Запуск (`src/main/index.ts` и рядом; логику вынести в отдельный модуль с тестами, `index.ts` не увеличивать больше чем на 10 строк):
  - ключ шлюза задан — основное окно не открывается, сразу появляется ёж со строкой ввода (как при вызове по клавише, источник — запуск); микрофон включается по тем же правилам, что при обычном вызове;
  - ключа нет (первый запуск) — открывается основное окно на экране «Подключения», ёж не появляется;
  - запуск вместе с Windows в скрытом режиме — как сейчас, ничего не показывается;
  - стенд (`TISHKA_STAND=1`) — как сейчас.
- Основное окно по-прежнему открывается из значка возле часов, из карточки ежа («Открыть в чате») и повторным запуском приложения.
- Реплика, отправленная из чата основного окна, пока это окно в фокусе: ёж не появляется, если был скрыт; если был на экране — показывает только состояние (думает, говорит), без облачка с текстом и без карточки, чтобы ответ не дублировался. Ответ виден в чате. Для этого источник реплики (окно чата или ёж) передаётся от окна до модели состояния ежа (`src/pet/state.ts`).
- Напоминания и уведомления по расписанию показываются у ежа, как раньше.
- `README.md`: поправить раздел «Первая настройка» и пункты проверки под новое поведение.
- `docs/contracts.md`: если меняются каналы или события — описать.

## Как проверить

Тесты: выбор того, что показать при запуске (ключ есть, ключа нет, скрытый запуск, стенд); реплика из чата при скрытом еже — ёж остаётся скрытым; реплика из чата при видимом еже — нет облачка и карточки; реплика из строки ежа — облачко и карточка как раньше; уведомление по расписанию показывается у ежа.

`npm run typecheck`, `npx vitest run --maxWorkers=2`, `npm run build`.

## Не делать

Не трогать `src/core/agent`, `src/core/llm`, `src/voice`, `src/renderer/settings`, расчёт положения и размеров окна ежа (`src/pet/layout.ts`, перетаскивание в `src/main/pet-window.ts`). Файлы не длиннее 200 строк. Стили только в css.
