# 47. Калибровка чувствительности микрофона

## Цель

Порог, по которому Тишка отличает речь от тишины, подбирается под конкретный микрофон и комнату: человек нажимает «Откалибровать», несколько секунд молчит, затем говорит фразу обычным голосом — и порог выставляется сам. Три готовых уровня («низкая», «обычная», «высокая») остаются запасным ручным вариантом.

## Изменение контракта

В `docs/contracts.md` в `Config.voice` добавлено:

```ts
mic: { threshold: number | null; noise: number | null; speech: number | null; calibratedAt: string | null };
```

`threshold` — порог громкости кадра (RMS, 0..1), `null` — калибровки не было, работает `sensitivity`. Перенести в типы, значения по умолчанию (`null`) и разбор настроек.

## Что сделать

### Расчёт

`src/voice/calibration.ts` — чистые функции:

```ts
function measureNoise(levels: number[]): { noise: number; peak: number };          // по кадрам тишины: медиана и 95-й процентиль
function measureSpeech(levels: number[], noisePeak: number): { speech: number; loudFrames: number };   // уровень тихих частей речи: 30-й процентиль кадров громче noisePeak
function computeThreshold(noisePeak: number, speech: number): { threshold: number; quality: 'good' | 'weak' | 'bad'; ratio: number };
```

- `threshold` — среднее геометрическое между `noisePeak` и `speech`, но не ниже `noisePeak × 1,5` и не выше `speech × 0,7`; нижний предел 0,0015.
- `ratio = speech / noisePeak`. `good` — не меньше 4; `weak` — от 2 до 4 (работать будет, но тихую речь может пропускать); `bad` — меньше 2 или речи не слышно (`loudFrames` меньше 10): порог не сохраняется.

### Порог в определении речи

`createVad` получает необязательный `threshold`. Если он задан: порог речи — `max(threshold, шум × 1,5)`, где шум — текущая скользящая оценка (чтобы внезапный фон не считался речью); коэффициенты `sensitivity` не применяются. Если не задан — прежнее поведение. Порог передаётся во все места записи: одиночная запись, постоянное прослушивание в окне-питомце и в чате, проверка микрофона.

### Мастер калибровки

В группе «Микрофон» раздела «Голос» — кнопка «Откалибровать микрофон». Мастер идёт внутри раздела, без отдельного окна; логика шагов — в отдельном модуле без разметки (`src/renderer/settings/calibration-flow.ts`), чтобы проверять тестами:

1. **Тишина, 3 секунды.** Текст: «Помолчите три секунды — слушаю комнату». Полоска уровня, обратный отсчёт. Первые 300 мс после открытия микрофона не учитываются.
2. **Речь, до 8 секунд.** Текст: «Теперь скажите обычным голосом: „Тишка, какие у меня сегодня встречи?“». Полоска уровня; шаг завершается через 1,5 секунды тишины после речи или по времени.
3. **Итог.** Полоска с тремя отметками — шум, порог, речь — и вывод словами:
   - `good`: «Готово. Тишка хорошо вас слышит»;
   - `weak`: «Слышу, но слабо. Сядьте ближе к микрофону или прибавьте уровень микрофона в настройках звука Windows» — порог сохраняется;
   - `bad`: «Не получилось: речь почти не отличается от шума» или «Речь не услышана» — порог не сохраняется, кнопка «Повторить».
   Записанная на шаге 2 фраза обрезается по новому порогу и отправляется в распознавание; распознанный текст показывается: «Я услышал: …». Если текст пустой — итог не лучше `weak`.
4. Кнопки «Сохранить» (пишет `mic` в настройки, применяется сразу, без перезапуска) и «Отмена». Во время мастера постоянное прослушивание и режим разговора приостанавливаются и возвращаются после.

Рядом с кнопкой — состояние: «Откалиброван сегодня в 15:40» или «Не откалиброван — работает общий уровень чувствительности», и кнопка «Сбросить калибровку».

Выбор «Чувствительность микрофона» остаётся; при сохранённой калибровке под ним подпись «Используется калибровка; уровень применяется, если её сбросить».

### Подсказка о калибровке

Если за одну сессию три раза подряд получено «Не расслышал» или запись закончилась без речи, а калибровки нет — в облачке один раз за запуск: «Плохо слышу. Откалибруйте микрофон в разделе „Голос“» (текстом, без речи вслух).

## Как проверить

Тесты `tests/calibration.test.ts`:

- шум 0,002 (пики 0,003), речь 0,03 → порог между ними, `good`;
- шум 0,01, речь 0,03 → `weak`, порог не ниже шума × 1,5 и не выше речи × 0,7;
- шум 0,02, речь 0,03 → `bad`;
- одни тихие кадры на шаге речи → `bad`, «Речь не услышана».

Тесты VAD: с заданным порогом 0,006 речь уровня 0,008 считается речью при любой `sensitivity`; при фоне, выросшем до 0,01, порог поднимается и фон речью не считается.

Тесты мастера (подменный микрофон и время): три шага идут по порядку; «Сохранить» пишет `mic` в настройки; `bad` не сохраняет и предлагает повторить; «Отмена» ничего не меняет; постоянное прослушивание приостановлено на время мастера и возвращено после.

Тест подсказки: три «Не расслышал» подряд без калибровки → одно сообщение; с калибровкой — нет.

`npm run typecheck`, `npx vitest run --maxWorkers=2`, `npm run build`.

## Не делать

Выбор устройства микрофона из списка, изменение системной громкости микрофона, шумоподавление своими средствами.
