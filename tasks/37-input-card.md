# 37. Карточка ввода и копирование с форматированием

## Цель

Тишка может попросить у человека большой текст: «Пришли текст, оформлю по шаблону». Под ёжиком появляется карточка с большим полем, человек вставляет текст, Тишка обрабатывает его и отдаёт результат в карточке, из которой копируется только сам результат — с форматированием.

Пример: «Тишка, отформатируй по шаблону итог недели» → карточка ввода «Текст для итога недели» → человек вставляет заметки и нажимает «Отправить» → карточка с готовым текстом и кнопкой «Копировать».

## Изменение контракта

В `docs/contracts.md` в `Reply` добавлено поле:

```ts
interface Reply {
  say: string;
  show?: Panel;
  ask?: { title: string; placeholder?: string };   // просьба прислать текст: окно показывает карточку ввода
  mood?: Mood;
}
```

Событие с репликой пользователю несёт `ask` так же, как `show`. Перенести в типы.

## Что сделать

### Ядро

- Служебный инструмент `reply` принимает необязательный `ask` (`title` — строка, `placeholder` — необязательная строка). Неверная форма `ask` отбрасывается, ответ остаётся рабочим. `ask` и `show` в одном ответе допустимы.
- В системное сообщение (там же, где правило «часть вслух, часть в карточку») добавить правило: если для выполнения просьбы нужен текст, которого человек ещё не дал (заметки, письмо, список, черновик), — не проси диктовать и не выдумывай, а коротко попроси вслух и передай `ask` с заголовком, что именно прислать. Когда текст получен — результат целиком в `show` вида `text`, в `markdown` только сам результат: без вступлений «Вот ваш текст», без пояснений и вопросов; пояснение, если нужно, — в `say`.
- Текст, отправленный из карточки ввода, приходит в ядро обычным `handleUserText` — отдельной ветки нет, история диалога связывает его с просьбой.

### Карточка ввода

`src/renderer/shared/ask-card.ts` — общая для чата и окна-питомца:

- заголовок из `ask.title`, многострочное поле (`textarea`) с `placeholder`, высота около 8 строк, прокрутка внутри, вставка текста любого размера до 20 000 символов (длиннее — подсказка «Слишком длинный текст» и неактивная кнопка);
- кнопки «Отправить» и «Отмена»; Ctrl+Enter отправляет, Esc отменяет; пустой текст не отправляется;
- при появлении карточки поле получает фокус;
- после отправки карточка заменяется строкой «Текст отправлен», Тишка переходит в состояние «думает».

В окне-питомце карточка ввода занимает место карточки результата (одновременно показывается одна), окно на это время принимает фокус и не прячется при потере фокуса, пока в поле есть текст. В окне чата карточка ввода показывается под репликой Тишки; отправленный текст попадает в ленту как сообщение человека, длинный — свёрнутым до 6 строк с «Показать целиком».

### Копирование с форматированием

- Кнопка «Копировать» у карточки вида `text` кладёт в буфер обмена сразу два представления: `text/html` — результат `renderMarkdown(panel.markdown)` (заголовки, списки, жирный текст, ссылки) и `text/plain` — текст без знаков разметки (`**`, `#`, обратные кавычки убраны, пункты списков начинаются с «• » или номера). Заголовок карточки в буфер не попадает.
- Запись в буфер — через главный процесс (`clipboard.write({ html, text })`), новый канал рядом с существующим каналом копирования. Вставка в Outlook, Word и Confluence даёт оформленный текст, вставка в блокнот — чистый.
- Функция преобразования разметки в простой текст — `markdownToPlain(markdown: string): string` в `src/renderer/shared/markdown.ts`.
- Остальные виды карточек копируются как раньше.

## Как проверить

Тесты:

- `reply` с `ask` → в ответе и в событии есть `ask`; `ask` без `title` отбрасывается.
- Системное сообщение содержит правило про `ask`.
- Карточка ввода (jsdom): пустой текст не отправляется; Ctrl+Enter вызывает отправку с текстом поля; Esc вызывает отмену; текст длиннее предела блокирует кнопку.
- `markdownToPlain`: `"## Итог\n- **Сделано**: отчёт\n- [ссылка](https://a.b)"` → `"Итог\n• Сделано: отчёт\n• ссылка (https://a.b)"`.
- Копирование карточки `text` вызывает запись с `html` и `text`; в `html` нет заголовка карточки.
- `npm run typecheck`, `npm test`, `npm run build`.

Скрипт `scripts/check-ask.ts`: на живом шлюзе фраза «Отформатируй по шаблону итог недели» → в ответе есть `ask`; затем отправляется текст-заметки → в ответе `show` вида `text`, в `markdown` нет вступительной фразы.

## Не делать

Вложение файлов, перетаскивание, хранение шаблонов (шаблон задаётся навыком или фразой), правки стилей ёжика.
