# 29. Страница-стенд персонажа

## Цель

Отдельная страница, на которой художник проверяет персонажа без остального приложения: включает клипы, двигает рот, отражает, смотрит на светлом и тёмном фоне, проигрывает состояния так, как их покажет окно-питомец.

## Что сделать

### Страница

`src/renderer/stand/index.html`, `stand.ts`, `stand.css` — новая страница сборки (добавить вход `stand` в `electron.vite.config.ts`). Политика безопасности такая же, как у окна-питомца: без тегов и атрибутов `style`, стили только в файлах css.

Слева — сцена с персонажем, справа — панель управления:

- **Клипы.** Кнопка на каждый клип из `character.clips()`; текущий подсвечен. Если клип есть в `CLIP_NAMES`, но персонаж его не отдаёт в `clips()`, кнопка серая с пометкой «нет в файле».
- **Рот.** Ползунок 0–1 → `setMouth`; кнопка «Говорить» — рот двигается сам по синусоиде с шумом 4–6 раз в секунду, имитируя речь, пока кнопка включена; рядом текущее значение.
- **Отражение.** Флажок → `setFlip`.
- **Фон.** Светлый, тёмный, шахматка (для проверки прозрачности), «рабочий стол» (серо-синий градиент).
- **Размер.** Ползунок масштаба сцены 50–200 %; рамка 200×200 px показывает место, которое персонаж занимает в окне-питомце (флажок «Показать рамку»).
- **Состояния.** Кнопка на каждое состояние окна-питомца (`appear`, `idle`, `listening`, `thinking`, `working`, `talking`, `notify`, `happy`, `confused`, `sleep`, `leave`): ставит клип и отражение через `clipForState`, как это делает окно.
- **Сценарий.** Кнопка «Проиграть сценарий»: appear → idle → listening → thinking → working → talking (рот двигается) → happy → idle → leave, по 2 секунды на шаг; текущий шаг подписан; кнопка «Стоп».
- **Сведения.** Имя источника персонажа, список клипов, которых не хватает из обязательных (`idle`, `walk`, `listen`, `talk`), время загрузки в миллисекундах, ошибки загрузки — текстом на странице.

Логику, не зависящую от разметки (последовательность сценария, имитация речи, список недостающих клипов), вынести в `src/renderer/stand/stand-logic.ts`.

### Источник персонажа

- `src/renderer/pet/character-factory.ts`: `createCharacter(kind: string): Character` — пока знает только `svg` (ёжик-заглушка). Окно-питомец и стенд создают персонажа через неё, чтобы новый формат подключался в одном месте.
- На стенде — выпадающий список источников (сейчас один пункт «Заглушка SVG») и кнопка «Перезагрузить» (`dispose` и `mount` заново).

### Запуск

- В значке области уведомлений — пункт «Стенд персонажа», открывает страницу в отдельном окне 900×640 с заголовком «Тишка — стенд персонажа». Окно создаётся в `src/main/stand-window.ts`, одно на приложение.
- Команда `npm run stand` в `package.json`: запускает приложение сразу со стендом (переменная окружения `TISHKA_STAND=1`: при старте открывается окно стенда вместо окна чата; окно-питомец и ядро работают как обычно).

## Как проверить

Тесты `tests/stand-logic.test.ts`:

- сценарий отдаёт шаги в описанном порядке, «Стоп» прерывает;
- список недостающих обязательных клипов: у персонажа без `walk` в списке `walk`;
- имитация речи отдаёт значения в диапазоне 0–1.

Тест `tests/character-factory.test.ts` (jsdom): `createCharacter('svg')` возвращает персонажа с десятью клипами; неизвестный вид — понятная ошибка.

`npm run typecheck`, `npm test`, `npm run build` — в сборке есть страница `stand`.

## Не делать

Подключение файлов Rive, Spine, DragonBones или glTF (задача 30), правки окна чата и настроек, изменение ёжика-заглушки.
