# 76. Звук пропадает: служба синтеза падает на отдельных фразах, Тишка после этого молчит

Найдено: на фразе «Не понял, что значит «раскладовка письма». Это шаблон, структура для будущего письма или что-то другое?» служба синтеза (`services/voice-lab/tts_server.py`) отвечает 500 с текстом `Required inputs (['token_type_ids']) are missing from input feed (['input_ids', 'attention_mask'])` — падает расстановка ударений внутри лаборатории голосов (модель омографов RuAccent). Другие фразы синтезируются. После одной такой ошибки приложение (`src/main/pet-speak.ts`) считает голос недоступным на 60 секунд и молчит на всех следующих репликах, сообщение «Голос недоступен, говорю текстом» показывается один раз за запуск.

## Что сделать

### Служба (`services/voice-lab/tts_server.py`, тесты `test_tts_server.py`)

- Синтез куска текста, упавший с исключением, повторяется один раз без расстановки ударений. В лаборатории расстановкой управляет поле синтезатора `ruaccent`: `None` — ещё не загружена, объект — загружена, `False` — выключена. На время повтора поле выставляется в `False`, после повтора возвращается прежнее значение (в `finally`). Если у синтезатора такого поля нет — повтор просто ещё раз тем же вызовом.
- Если и повтор упал — этот кусок пропускается; ответ 500 только когда не удалось синтезировать ни одного куска.
- В строке журнала запроса отмечать, сколько кусков ушло на повтор и сколько пропущено.

### Приложение (`src/voice/tts-client.ts`, `src/main/pet-speak.ts`)

- Различать два сбоя: служба не отвечает (нет соединения, тайм-аут, 503) и служба ответила ошибкой на конкретный текст (400, 422, 500). Во втором случае голос недоступным не считается: реплика остаётся текстом, следующая реплика синтезируется как обычно, пауза 60 секунд не включается.
- Когда служба действительно недоступна: пауза перед следующей попыткой 15 секунд вместо 60; сообщение «Голос недоступен, говорю текстом» показывается при каждом переходе из рабочего состояния в недоступное, а не один раз за запуск. При восстановлении голос возвращается без действий человека.
- Кнопка «Сказать пример» в настройках всегда делает настоящую попытку, не глядя на паузу.

## Как проверить

Служба: тесты с подставным синтезатором — исключение на первом вызове и успех на повторе с `ruaccent == False` во время повтора и прежним значением после; оба вызова упали → кусок пропущен, остальные в ответе; все куски упали → 500. `python -m unittest` в каталоге службы (или как запускаются существующие тесты службы).

Приложение: тесты — ответ 500 на одну реплику не глушит следующую; обрыв соединения даёт паузу 15 секунд и сообщение; после восстановления следующая реплика звучит; повторный уход в недоступность снова даёт сообщение. `npm run typecheck`, `npx vitest run --maxWorkers=2`, `npm run build`.
