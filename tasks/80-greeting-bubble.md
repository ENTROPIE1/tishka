# 80. Приветствие вслух и текст в облачке расходятся

Шаги: вызвать ежа (запуск, клавиша, имя). Получилось: вслух звучит «Фыр. Я здесь.», а в облачке написано «Слушаю…». Ожидание: в облачке тот же текст, что звучит.

## Причина (проверить)

Приветствие выбирается в `src/main/pet-speak.ts` (нейтральное, пока запись не идёт; «Фыр. Слушаю.», когда идёт — задача 75). Облачко ставит `src/renderer/pet/listen-ui.ts` по своему правилу: при включении записи показывает `LISTEN_SAY` («Слушаю…») независимо от того, что звучит.

## Что сделать

- Пока звучит приветствие, в облачке — текст этого приветствия, дословно тот, что произносится (источник текста один — заготовки `src/voice/canned.ts`).
- «Слушаю…» в облачке — только когда запись действительно идёт и ёж ничего не произносит и не показывает ответ. После окончания приветствия, если запись идёт, облачко сменяется на «Слушаю…».
- Если речь вслух выключена в настройках, при появлении облачко показывает то приветствие, которое прозвучало бы, затем по тому же правилу «Слушаю…».
- Подпись состояния под ежом («слушает», «ждёт», «говорит») согласована с облачком: во время приветствия — «говорит», после — «слушает» при идущей записи.

## Как проверить

Тесты: появление с неготовой записью → облачко с нейтральным приветствием, без «Слушаю…»; появление с идущей записью → облачко с приветствием «Фыр. Слушаю.», после конца речи — «Слушаю…»; речь выключена → облачко с приветствием. `npm run typecheck`, `npx vitest run --maxWorkers=2`, `npm run build`.

## Не делать

Не менять сами тексты заготовок и логику включения записи. Не трогать `src/voice/wake-flow.ts`. Создаваемые файлы не длиннее 200 строк.
