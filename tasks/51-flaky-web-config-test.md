# 51. Нестабильный тест `tests/web-config.test.ts`

## Цель

Тест «при web.enabled false инструменты чтения не зарегистрированы» изредка падает, когда тесты идут под нагрузкой (одновременно работают другие процессы тестов), и проходит при повторном запуске. Сделать его устойчивым.

## Что сделать

- Найти причину: вероятнее всего, общий или не до конца удалённый временный каталог данных, ожидание по реальному времени, незавершённые таймеры ядра после теста или зависимость от порядка тестов.
- Исправить причину, а не увеличивать таймаут: у каждого теста свой уникальный временный каталог (`mkdtemp`), ядро останавливается в `afterEach` (`stop`) и дожидается завершения записи, каталог удаляется с повторами (`rm` с `maxRetries`), реального времени и сети в тесте нет.
- Просмотреть соседние тесты, которые поднимают ядро целиком (`createTishkaCore`), и привести к тому же образцу, если у них та же слабость. Общий помощник для таких тестов — в `tests/` рядом с существующими помощниками.

## Как проверить

- `npx vitest run tests/web-config.test.ts` 20 раз подряд — все проходят.
- Полный прогон `npx vitest run --maxWorkers=2` 3 раза подряд — все проходят.
- `npm run typecheck`, `npm run build`.

## Не делать

Изменение кода приложения, кроме случая, когда причина в нём (тогда описать в отчёте).
