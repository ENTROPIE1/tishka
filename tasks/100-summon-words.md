# 100. «Тишка, приходи» уходит в ядро как просьба «приходи»

Человек зовёт: «Тишка, приходи». Имя распознано, ёж появляется, а остаток фразы «приходи» выполняется как просьба: Тишка отвечает «Я и так тут, на экране. А что нужно?». Через несколько секунд в ленте ещё и строка «Не расслышал».

Причины в `src/voice/wake-flow.ts`, `routeWake`:

1. Остаток фразы после имени, состоящий только из слов вызова, считается просьбой. Сделать: слова вызова (отдельный список рядом со словами ухода в `src/voice/wake.ts`) — «приходи», «приди», «иди сюда», «подойди», «появись», «покажись», «выходи», «вылезай», «ты где», «ты тут», «ты здесь», «ау», «эй», «сюда», «ко мне», «нужен», «ты нужен», в том числе с «пожалуйста» и в сочетаниях («иди сюда, пожалуйста») — обрабатываются как вызов без просьбы: ёж появляется с обычным приветствием и слушает. Если после слов вызова есть настоящая просьба («Тишка, иди сюда, какие у меня встречи») — в ядро уходит только просьба. То же в разговоре, когда ёж уже на экране: «Тишка, ты тут?» — короткий готовый ответ без обращения к модели («Фыр, я здесь»).
2. Когда во фразе с именем есть просьба, вместе с отправкой просьбы в ядро запускается ещё и отдельная запись (`startListen`), которая заканчивается строкой «Не расслышал» в ленте. Сделать: при просьбе в той же фразе отдельная запись не запускается, включается разговор (как сейчас), и «Не расслышал» после вызова по имени человеку не показывается.

Сценарии в `tests/scenarios`: «Тишка, приходи» — ёж появился, в ядро ничего не ушло, в ленте нет «Не расслышал»; «Тишка, иди сюда, который час» — в ядро ушло «который час»; «Тишка, какие встречи» — в ядро ушло, лишней записи и «Не расслышал» нет; «Тишка, ты тут?» в разговоре — готовый ответ, модель не вызывалась. Тесты модуля на список слов. `npm run typecheck`, `npm run test:scenarios`, `npx vitest run --maxWorkers=1` (проверки по одной), `npm run build`. Файл `wake-flow.ts` не увеличивать.
