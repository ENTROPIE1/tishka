# 110. Медленное распознавание не копит очередь; подпись подключения без секретов

## Что сделать

1. Медленное распознавание. При локальном распознавании фраза обрабатывается 4,5–5,5 с, а отрезки по 4 с идут подряд: очередь растёт, ответ приходит через десятки секунд. Сделать: распознавание идёт по одному отрезку; пока оно занято, новые отрезки не выстраиваются в очередь — хранится только самый свежий, прежний ожидающий отбрасывается (строка в журнале времени `stt.drop reason=busy`). Если три распознавания подряд длились дольше отрезка, в «Подключениях» у блока распознавания появляется подсказка: «Распознавание на этом компьютере медленное. Подключите готовую службу распознавания» со ссылкой на поле адреса. Подсказка пропадает после быстрого распознавания.
2. Подпись подключения. `mcpSignature` в `src/core/app.ts` для сравнения настроек хранит строку с раскрытыми секретами. Заменить на хеш SHA-256 от той же строки; сама строка в памяти не сохраняется.

## Как проверить

Тесты: три отрезка пришли, пока идёт распознавание первого, — распознаётся первый и последний, средние отброшены; подсказка появляется после трёх медленных и пропадает после быстрого; подпись — хеш, одинаковые настройки дают одинаковую подпись, смена секрета меняет её, в подписи нет текста секрета. `npm run typecheck`, `npm run test:scenarios`, `npx vitest run --maxWorkers=1` (проверки по одной), `npm run build`.

## Не делать

Не менять правило вызова по имени, пороги и окно ежа.
