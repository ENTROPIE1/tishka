# 82. «Слушаю…» убрать из облачка: состояние микрофона показывают значок и подпись

Сейчас при запуске в облачке сначала «Фыр. Я здесь», потом оно сменяется на «Слушаю…». Выглядит как два приветствия подряд. Облачко — для слов Тишки, состояние записи — для значка микрофона и подписи под ежом.

## Что сделать

- Надпись «Слушаю…» в облачке ежа не показывается никогда: ни после приветствия, ни при включении разговора щелчком, ни при вызове клавишей. Правило облачка (`bubbleSay` в `src/renderer/pet/listen-ui.ts`): текст ответа, приветствия, статуса или ошибки; если показывать нечего — облачко скрыто.
- Приветствие в облачке держится, пока звучит (или столько, сколько звучало бы при выключенной речи), затем облачко гаснет.
- Произносимое приветствие не меняется: при готовой записи Тишка по-прежнему говорит «Фыр. Слушаю.» и этот текст виден в облачке, пока звучит; при неготовой — нейтральное.
- То, что запись идёт, видно по двум признакам, оба обязательны: значок микрофона в строке ввода в активном (оранжевом) виде с полоской уровня; подпись под ежом «слушает». Ожидание службы — значок в виде ожидания, подпись «ждёт». Запись выключена — значок обычный, подпись соответствует состоянию ежа. Проверить, что значок действительно активен во всех случаях идущей записи: появление при запуске после готовности службы, вызов по имени, клавишей, щелчок по микрофону (в очереди замечание: значок серый при идущей записи).
- Окно чата основного окна не трогать: там надпись про прослушивание остаётся.
- Сценарные тесты (`tests/scenarios`, задача 81): ожидания «облачко „Слушаю…“» заменить на «облачко скрыто, значок активен, подпись „слушает“».

## Как проверить

Тесты: `bubbleSay` не возвращает «Слушаю…» ни при каких входах; после конца приветствия облачко пустое; значок и подпись соответствуют записи в четырёх случаях включения. `npm run typecheck`, `npm run test:scenarios` (если команда уже есть), `npx vitest run --maxWorkers=2`, `npm run build`.

## Не делать

Не менять тексты заготовок и логику включения записи. Не трогать `src/voice/wake-flow.ts`.
