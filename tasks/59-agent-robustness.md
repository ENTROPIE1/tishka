# 59. Агент: «Новый разговор» во время ответа и пустой ответ модели

Находки 4 и 6 из `tasks/reports/54-core.md` (там же тесты).

## Что сделать

- «Новый разговор», нажатый во время ответа, не портит контекст: сброс выполняется между ходами (в той же очереди, что и обработка реплик) либо текущий ход помечается отменённым и больше ничего не пишет в историю агента. После этого следующая реплика уходит модели как `[system, user]`. Разделитель в истории чата появляется сразу, как и сейчас.
- Пустой ответ модели (пустой или отсутствующий текст, нет вызовов инструментов) и вызов `reply` без `say` и без панели дают понятную реплику «Не получилось ответить, попробуй ещё раз» с настроением `confused`, а не пустое облачко.

## Как проверить

Тесты из отчёта (перенести в `tests/`), плюс: `content: null`; `reply` с пустым `say`, но с панелью — панель показывается, `say` не подменяется.

`npm run typecheck`, `npx vitest run --maxWorkers=2`, `npm run build`.

## Не делать

Не трогать `src/renderer`, `src/main`, `src/core/mcp`, `src/core/skills`, `src/core/triggers`, `src/core/llm`. В `src/core/app.ts` менять только `newConversation`. Файлы не длиннее 200 строк.
