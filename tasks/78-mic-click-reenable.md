# 78. Микрофон у ежа не включается щелчком

Шаги: ёж на экране, разговор включён. Щёлкнуть микрофон в строке ввода — разговор выключился. Щёлкнуть ещё раз — ничего не происходит, значок не меняется, запись не идёт. Включить микрофон щелчком нельзя, пока ёж не будет вызван заново.

## Причина

`src/voice/wake-flow.ts`, `toggleConversation`: после выключения щелчком ставится флаг `suppressed`, и ветка включения для окна ежа под этим флагом не выполняется. Флаг задуман против автоматического включения (по реплике, по появлению), а блокирует и явный щелчок человека.

## Что сделать

- Щелчок по микрофону в строке ежа всегда переключает разговор: выключен → включить, включён → выключить. Явное включение щелчком снимает флаг `suppressed`.
- Флаг `suppressed` действует только на автоматическое включение разговора до конца текущего появления ежа, как и задумано.
- Если разговор сейчас принадлежит окну чата (`owner === 'chat'`), щелчок по микрофону ежа забирает разговор ежу (чат получает выключение), а не игнорируется.
- Если распознавание не готово, щелчок не молчит: показывается существующее сообщение о причине (служба запускается или не настроена), значок остаётся выключенным.
- Значок в строке ежа всегда отражает действительное состояние: окно получает подтверждение состояния после каждого щелчка, в том числе когда включение не состоялось.

## Как проверить

Тесты `wake-flow`: выключить щелчком → щелчок снова включает; после выключения щелчком автоматическое включение по реплике в том же появлении не происходит; после нового появления автоматическое включение работает; щелчок при владельце «чат» переводит разговор ежу; щелчок при неготовой службе даёт сообщение и состояние «выключен». `npm run typecheck`, `npx vitest run --maxWorkers=2`, `npm run build`.

## Не делать

Не менять таймер тишины, уход, распознавание имени. Править в `wake-flow.ts` только затронутые функции; новые вспомогательные функции выносить в соседний модуль, а не увеличивать этот файл.
