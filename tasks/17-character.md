# 17. Персонаж: переходник и ёжик-заглушка

## Цель

Окно-питомец управляет персонажем через три действия: включить клип, задать открытие рта, отразить по горизонтали. Формат настоящего файла персонажа пока не выбран, поэтому за переходником стоит нарисованный кодом ёжик. Когда появится настоящий файл, меняется только реализация переходника.

## Что сделать

`src/renderer/pet/character.ts`

```ts
type ClipName = 'idle' | 'walk' | 'listen' | 'think' | 'work' | 'talk' | 'notify' | 'happy' | 'confused' | 'sleep';

interface Character {
  mount(container: HTMLElement): Promise<void>;
  setClip(name: ClipName): void;        // неизвестный или отсутствующий клип заменяется на idle
  setMouth(level: number): void;        // 0..1, значения вне диапазона обрезаются
  setFlip(flipped: boolean): void;      // true — смотрит влево
  clips(): ClipName[];                  // какие клипы есть у этой реализации
  dispose(): void;
}

function clipForState(state: PetState): { clip: ClipName; flip: boolean };
```

Соответствие состояний и клипов:

| Состояние | Клип | Отражение |
|---|---|---|
| `appear` | `walk` | влево (идёт от правого края) |
| `leave` | `walk` | вправо |
| `idle` | `idle` | — |
| `listening` | `listen` | — |
| `thinking` | `think` | — |
| `working` | `work` | — |
| `talking` | `talk` | — |
| `notify` | `notify` | — |
| `happy` | `happy` | — |
| `confused` | `confused` | — |
| `sleep` | `sleep` | — |
| `hidden` | `idle` | — |

`src/renderer/pet/svg-hedgehog.ts` — реализация `Character` на SVG и CSS, без картинок и без библиотек:

- Ёжик рисуется кодом из простых фигур: тело, иголки, мордочка, нос, глаза, рот, уши, четыре лапы. Размер 200×200, прозрачный фон. Тёплые коричневые тона, должен хорошо читаться и на светлом, и на тёмном фоне (тонкая светлая обводка).
- Части — отдельные группы SVG с понятными `id`, чтобы их можно было двигать.
- Клипы — классы на корневом элементе и CSS-анимации:
  - `idle`: медленное «дыхание» тела, моргание раз в несколько секунд;
  - `walk`: лапы попеременно, лёгкое покачивание;
  - `listen`: голова наклонена, уши приподняты;
  - `think`: взгляд вверх, покачивание;
  - `work`: передние лапы двигаются;
  - `talk`: то же, что `idle`, рот управляется `setMouth`;
  - `notify`: подпрыгивание и взмах лапой;
  - `happy`: короткий подскок, глаза-дуги;
  - `confused`: голова набок, лапа у головы;
  - `sleep`: глаза закрыты, медленное дыхание.
- `setMouth`: высота рта от закрытого до открытого плавно по значению.
- Пока нет голоса и события `speak.level` не приходят, в состоянии `talking` рот двигается сам: значение меняется по времени, как при речи.
- При системной настройке «уменьшить движение» (`prefers-reduced-motion`) анимации отключаются, клипы различаются только позой.

Подключение в `src/renderer/pet/pet.ts`: заглушка-прямоугольник из задачи 16 заменяется персонажем; состояние переводится в клип через `clipForState`; событие `speak.level` передаётся в `setMouth`.

## Как проверить

Тесты `tests/character.test.ts` (среда `jsdom` для этого файла; пакет `jsdom` разрешён в dev-зависимостях):

- `clipForState` для каждого состояния даёт клип и отражение из таблицы.
- После `mount` в контейнере есть SVG с группами тела, иголок, глаз, рта и лап.
- `setClip('talk')` ставит на корень класс клипа и убирает прежний.
- `setClip` с неизвестным именем включает `idle`.
- `setMouth(2)` и `setMouth(-1)` обрезаются до 1 и 0; значение отражается в размере рта.
- `setFlip(true)` отражает персонажа, `setFlip(false)` возвращает.
- `clips()` возвращает все десять клипов.
- `dispose` очищает контейнер и останавливает таймеры.

Проверка вручную: `npm run dev`, Тишка выходит из-за края ёжиком, идёт лапами, при ответе двигает ртом, уходит в другую сторону.

## Не делать

Подключение файлов Rive, Spine, DragonBones или glTF, страницу-стенд, синтез речи.
