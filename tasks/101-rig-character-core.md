# 101. Новый персонаж «Тишка»: ядро проигрывателя костной модели

В `assets/tishka/model/` лежит костная модель нового персонажа: слои PNG 1200×1200 (`layers/`, `hands/`), скелет и раскладка (`rig.json`, `rig_data.js`), клипы (`clips.js`: idle, walk, listen, talk, think, work, found, notify, happy, confused, dance, kick, sleep), описания глаз, кистей, ртов и эффектов (`eyes_meta.js`, `hands_meta.js`, `fx_meta.js`), маски (`layers_meta.js`). Образец рабочего проигрывателя и редактора — `reference/player.html` (одна страница, canvas 2D); из него берётся логика, но не интерфейс редактора. Спрайты и клипы ещё будут меняться: проигрыватель читает данные из файлов, ничего из модели в код не зашивается.

## Что сделать

Модули в `src/renderer/character-rig/` (каждый не длиннее 200 строк, без зависимости от DOM там, где это возможно, чтобы тестировать):

1. `rig-data.ts` — типы и загрузка данных модели: скелет, слои с привязкой к костям и порядком, варианты (глаза, брови, рты, кисти, зрачки, эффекты, планшет), клипы. Исходные файлы в `assets/tishka/model/` остаются источником: добавить скрипт `scripts/build-character.ts`, который собирает из них один `model.json` рядом, и тест, что `model.json` соответствует исходникам.
2. `rig-pose.ts` — математика: мировые преобразования костей от родителя, ключи клипа `[время, поворот, сдвиг x, сдвиг y, растяжение]` с интерполяцией (плавной и линейной для костей из `linear`), цикл, переход `next`, плавное смешивание при смене клипа (как в образце).
3. `rig-show.ts` — «что показано»: глаза (форма, зрачок, моргание, подмигивание), брови, рот, кисти, эффекты, планшет; события `set` клипа по времени; автоматическое моргание, кроме клипов с `noBlink`.
4. `rig-draw.ts` — порядок рисования и рисование на `CanvasRenderingContext2D`: слои по порядку, `front` и `underTablet` из клипа, отсечение иголок и масок, как в образце. Физику иголок и ушей из образца (`physStep`) перенести, если она отделяется без переноса редактора; если нет — оставить на потом и написать об этом в отчёте.
5. `rig-player.ts` — проигрыватель: загрузка картинок, цикл кадров (останавливается, когда окно скрыто), `play(clip)`, `setShow(часть набора)`, `setMouth(форма | null)`, отражение по горизонтали, масштаб под размер контейнера с учётом плотности пикселей.

Страница-стенд (`src/renderer/stand/`): выбор персонажа «Первый ёж» / «Тишка»; для нового — кнопки всех клипов, выбор глаз, бровей, рта, кистей, эффектов.

## Как проверить

Тесты: интерполяция ключей и цикл; мировые преобразования цепочки костей; смена клипа со смешиванием; события `set` применяются в своё время; моргание не идёт в `noBlink`; порядок рисования с `front`; сборка `model.json`. `npm run typecheck`, `npx vitest run --maxWorkers=1` (проверки по одной, память машины ограничена), `npm run build`. В отчёте — список того, что перенесено и что отложено.

## Не делать

Не трогать окно ежа (`src/renderer/pet`), голос, ядро. Не переносить редактор костей. Не менять файлы в `assets/tishka/model/` (кроме добавления `model.json`).
