# 106. Автоматическое занесение встреч из почты в календарь

После задач 104 и 105 есть календарь и настройка источников. Встречи из подключений Exchange должны попадать в него сами.

## Что сделать

- Загрузка (`src/core/calendar/sync.ts`): для каждого подключения Exchange с включённым «Загружать встречи» ядро вызывает инструмент подключения `list_meetings` (сервер `mcp-servers/exchange`) на период «сегодня и 14 дней вперёд» и приводит результат к событиям календаря: `source: exchange:<имя>`, `externalId`, название, время, место, ссылка на подключение к встрече (если сервер её отдаёт; при необходимости дополнить сервер полями идентификатора, места, признака «весь день», статуса «отменена» — с тестами сервера).
- Слияние: новое — добавить, изменившееся — обновить (сохранив напоминание и заметку человека), исчезнувшее или отменённое — убрать. Свои события не трогаются. Повторная загрузка без изменений ничего не меняет и не шлёт событий.
- Когда: при запуске после подключения серверов, затем каждые 10 минут в рабочее время и каждые 30 минут вне его, сразу после кнопки «Обновить сейчас» и по просьбе Тишке «обнови календарь» (инструмент `calendar_sync`). Ошибка подключения не роняет календарь: в «Источниках» показывается время последней удачной загрузки и текст ошибки.
- Напоминания о загруженных встречах — по общему правилу задачи 104 (`defaultRemindMinutes`), с кнопкой «Подключиться» в уведомлении, если есть ссылка.
- Журнал времени: `calendar.sync.start`, `calendar.sync.end ok=… added=… updated=… removed=… ms=…`.
- `README.md`: короткий раздел «Календарь».

## Как проверить

Тесты на подставном подключении: первая загрузка, изменение времени встречи, отмена, исчезновение, сохранение заметки и напоминания человека, две загрузки подряд без изменений, ошибка подключения, выключенный источник не загружается, расписание загрузок по рабочему времени. Тесты сервера Exchange на новые поля. `npm run typecheck`, `npx vitest run --maxWorkers=1` (проверки по одной), `npm run build`, `npm run build:mcp`.

## Не делать

Не трогать окно ежа, голос, запись. Ничего не писать в почту и календарь Exchange: только чтение.

## Уточнение: загрузка встреч видна как автоматизация

Человек воспринимает это как автоматизацию «проверять почтовый календарь и переносить встречи в мой». На экране «Автоматизации» она показана отдельной встроенной карточкой «Встречи из почты в календарь»: включена или нет, по какому подключению, когда выполнялась в последний раз и сколько встреч добавила, изменила, убрала, кнопка «Запустить сейчас». Переключатель на карточке и переключатель в «Источниках» календаря — одна и та же настройка. Просьба Тишке «переноси мои встречи из почты в календарь» включает её (инструмент `calendar_sync` с параметром включения), «перестань» — выключает.
