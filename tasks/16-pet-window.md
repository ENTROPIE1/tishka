# 16. Окно-питомец

## Цель

Тишка живёт поверх экрана: выходит из-за правого края, когда его позвали или сработал триггер, показывает реплику облачком, содержание ответа — карточкой, и уходит, когда не нужен. В этой задаче — окно, его поведение и состояния. Сам персонаж пока прямоугольник-заглушка; рисунок и анимация — задача 17.

## Что сделать

### Состояния

`src/pet/state.ts` — чистая логика без `electron` и без DOM:

```ts
type PetState = 'hidden' | 'appear' | 'idle' | 'listening' | 'thinking' | 'working' | 'talking' | 'notify' | 'happy' | 'confused' | 'leave' | 'sleep';

interface PetModel {
  state: PetState;
  since: number;                 // мс, когда вошли в состояние
  say?: string;                  // текст в облачке
  panel?: Panel;                 // карточка
  queue: PetState[];             // состояния, которые нужно показать после текущего
}

function initialPet(now: number): PetModel;
function onEvent(model: PetModel, event: TishkaEvent, now: number, opts: { petMode: boolean }): PetModel;
function onTick(model: PetModel, now: number, opts: { petMode: boolean }): PetModel;   // переходы по времени
```

Переходы по событиям:

| Событие | Переход |
|---|---|
| `wake` | из `hidden` или `sleep`: `appear`, затем `listening`; из остальных: `listening` |
| `listen.start` | `listening` |
| `listen.end` | `thinking` |
| `think.start` | `thinking` |
| `tool.start` | `working` |
| `tool.end` | `thinking` |
| `reply` | запоминает `say` и `show`; состояние `talking`, а при `mood: 'happy'` сначала `happy`, при `mood: 'confused'` сначала `confused` |
| `speak.start` | `talking` |
| `speak.end` | `idle` |
| `notify` | из `hidden` или `sleep`: `appear`, затем `notify`; из остальных: `notify` после текущего состояния |
| `skill.saved` | `happy`, затем `idle` |
| `error` | `confused` |
| `idle` | `idle`, если сейчас не `talking` |

Переходы по времени (`onTick`):

- `appear` длится 900 мс, `leave` — 900 мс, `happy`, `confused`, `notify` — по 1500 мс; затем следующее состояние из очереди, а если очередь пуста — `idle`.
- `talking` без события `speak.end` (голоса ещё нет) длится 1500 мс плюс 60 мс на каждый знак `say`, но не дольше 12 секунд, затем `idle`.
- `idle` дольше 30 секунд: при `petMode: false` — `leave`, затем `hidden`; при `petMode: true` после 5 минут — `sleep`.
- Облачко и карточка сохраняются, пока Тишка на экране, и очищаются при `hidden`.
- Пока открыта карточка или пользователь вводит текст, окно сообщает об этом вызовом `onTick` с тем же `now` и пометкой занятости в `opts.busy: true` — тогда отсчёт простоя не идёт.

### Окно

`src/main/pet-window.ts` — создание и движение окна; `src/renderer/pet/`: `index.html`, `pet.ts`, `pet.css`. Четвёртая точка входа сборки.

- Окно без рамки, прозрачное, поверх всех окон, не показывается в панели задач, размер 440×560, не меняет размер. Положение — у правого нижнего угла рабочей области основного экрана.
- Появление и уход: окно сдвигается по горизонтали из-за правого края и обратно за 900 мс. В `hidden` окно скрыто.
- Перетаскивание персонажа мышью двигает окно вдоль нижнего края экрана; положение по горизонтали запоминается в настройках (`Config.pet.x`).
- Прозрачные участки окна пропускают щелчки мыши к окнам под ним (`setIgnoreMouseEvents` с пересылкой событий; переключается, когда указатель над персонажем, облачком или карточкой).
- Щелчок по персонажу — вызов: событие `wake` с `source: 'click'`, под облачком появляется поле ввода в одну строку; Enter отправляет текст (`sendUserText`), Esc закрывает поле.
- Глобальная горячая клавиша из `Config.voice.hotkey` делает то же самое с `source: 'hotkey'`. Если клавишу занять не удалось, событие `error` с понятным текстом, приложение продолжает работу.
- Облачко над персонажем показывает `say`. Пустой `say` — облачка нет.
- Карточка рядом с облачком показывает `show` тем же способом, что и окно чата (общий код отрисовки панелей и `renderMarkdown` вынести из `src/renderer/chat/` в `src/renderer/shared/` и использовать в обоих окнах). В карточке кнопки «Копировать», «Открыть в чате» (открывает окно чата) и крестик. Длинная карточка прокручивается внутри, высота не больше 300.
- Персонаж-заглушка: блок 200×200 с подписью текущего состояния. Его заменит задача 17.
- Значок в области уведомлений с меню: «Позвать Тишку», «Открыть чат», «Подключения», «Режим питомца» (переключатель `Config.petMode`), «Выход». Закрытие окна чата не завершает приложение: оно продолжает жить в области уведомлений.

### Контракт

В `docs/contracts.md` в `Config` добавлено `pet: { x: number | null }` — положение окна по горизонтали, `null` означает «у правого края». Перенести в типы, `defaultConfig` и `mergeConfig`.

## Как проверить

Тесты `tests/pet-state.test.ts`:

- `wake` из `hidden` даёт `appear`, через 900 мс — `listening`.
- `listen.end` → `thinking`; `tool.start` → `working`; `tool.end` → `thinking`.
- `reply` с текстом из 50 знаков: `talking`, через 1500 + 50·60 мс — `idle`; `say` и `panel` сохранены.
- `reply` с `mood: 'happy'`: сначала `happy`, затем `talking`.
- `notify` из `hidden`: `appear`, затем `notify`, затем `idle`.
- `notify` во время `talking` не обрывает его: `notify` наступает после.
- 30 секунд `idle` при `petMode: false` → `leave` → `hidden`, облачко и карточка очищены.
- При `petMode: true` ухода нет, через 5 минут — `sleep`; `wake` из `sleep` даёт `appear`.
- При `opts.busy: true` отсчёт простоя не идёт.
- `error` → `confused` → `idle`.

Проверка вручную: `npm run dev`; горячая клавиша вызывает Тишку, он выезжает из-за края; текст «утро пятницы» в поле ввода даёт облачко с репликой; через 30 секунд простоя он уезжает; значок в области уведомлений работает.

## Не делать
