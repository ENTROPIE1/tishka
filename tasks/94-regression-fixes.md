# 94. Исправления по отчёту о сломанном

Отчёт: `tasks/reports/93-regression-read.md`. Исправить пять находок и одно предположение, каждое со своим тестом.

1. Подсказка о калибровке в разговоре. После задач 77 и 79 «Не расслышал» всегда приходит с `empty: true`, и `onMissedSpeech` в `src/voice/wake-flow.ts` больше не вызывается. Разделить два случая: отсеянный шум (стук клавиш, ненадёжное распознавание) промахом не считается; пустой ответ службы на звук длиннее секунды — считается и зовёт `onMissedSpeech`. Человеку по-прежнему ничего не показывается.
2. «Остановлено» при остановке из чата не показывать в облачке ежа: в `src/pet/state.ts` событие статуса с источником «чат» ежом не отображается. Сценарий `stop-line` провести через ядро, а не прямой отправкой события.
3. Вытесненная из очереди реплика (`src/core/turn-queue.ts`) не пропадает молча: в ленте чата под ней появляется приглушённая строка «Не отвечал: пришёл новый вопрос»; в историю как ответ не пишется, ёж её не озвучивает.
4. Перезапуск службы распознавания при сохранении настроек (`src/main/voice-restart.ts`) завершает отложенное включение записи так же, как первый запуск: готовность и неудача доходят до `noteReady` и `noteFailed`.
5. `src/voice/stt-service.ts`, режим готовой службы: явный `start()` меняет состояние через `announce()`, окна узнают сразу.
6. Перетаскивание ежа: если кнопку мыши отпустили вне окна, перетаскивание и пауза записи завершаются (события `pointerup`, `pointercancel`, потеря фокуса окном) и в любом случае не позже чем через 10 секунд без движения.

`npm run typecheck`, `npm run test:scenarios`, `npx vitest run --maxWorkers=1`, `npm run build`. Файл `wake-flow.ts` не увеличивать: новое выносить в отдельные модули не длиннее 200 строк.
