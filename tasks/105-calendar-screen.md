# 105. Экран «Календарь» в основном окне

После задачи 104 есть хранилище календаря и обстановка. Нужен экран — место, где человек видит свою занятость и управляет ею.

## Что сделать

- Пункт «Календарь» в боковом меню основного окна (после «Автоматизации»), экран в `src/renderer/chat/calendar/` (модули не длиннее 200 строк), каналы в `src/main/ipc-calendar.ts`.
- Вверху — полоса обстановки: «Сейчас: рабочее время, свободен до 14:00» или «Идёт „Планёрка“ до 11:00, следующая „Демо“ в 14:00»; обновляется раз в минуту и при изменении календаря.
- Вид «День» (по умолчанию) и «Неделя»: шкала времени с подсвеченным рабочим временем, события блоками по времени, линия «сейчас», события на весь день — строкой сверху. Цвет и значок по виду события: встреча, занят, личное, напоминание, отсутствую; загруженные из почты помечены значком источника. Переход: сегодня, назад, вперёд.
- Под шкалой или справа — список «Сегодня»: события по порядку с временем, местом, кнопкой «Подключиться» (если есть ссылка), отметкой о напоминании.
- Создание: кнопка «Событие» и щелчок по пустому месту шкалы открывают карточку — название, вид, дата, начало, конец или «весь день», напоминание (нет, за 5, 10, 15, 30 минут), заметка. Быстрые кнопки: «Занят час», «Занят до конца дня» — создают событие `focus` от текущего времени.
- Правка и удаление своих событий; у загруженных и у событий расписания правятся только напоминание и заметка, удаления нет, есть подпись, откуда событие.
- Блок «Рабочее время» (сворачиваемый, на этом же экране): дни недели с началом и концом, обед, напоминать по умолчанию за N минут, «вне рабочего времени не напоминать вслух о рабочих встречах». Применяется сразу.
- Блок «Источники»: строка на каждое подключение Exchange с переключателем «Загружать встречи» (сама загрузка — задача 106; пока переключатель сохраняет настройку `calendar.sources`), время последней загрузки, кнопка «Обновить сейчас» (неактивна, пока нет задачи 106).
- Экран обновляется сам при изменениях из ядра (Тишка добавил событие голосом — оно появилось).
- Пустой календарь: подсказка «Скажите Тишке: „поставь в календарь встречу завтра в 15“ или нажмите „Событие“».

## Как проверить

Тесты (jsdom, как у других экранов): раскладка событий на шкале, включая пересекающиеся; линия «сейчас»; создание, правка, удаление; ограничения для загруженных событий; быстрые кнопки; сохранение рабочего времени; обновление при событии ядра; полоса обстановки. `npm run typecheck`, `npx vitest run --maxWorkers=1` (проверки по одной), `npm run build`. Вёрстка в стиле остальных экранов (`shell.css`, карточки настроек), тёмная тема, без горизонтальной прокрутки при ширине окна 900 точек.

## Не делать

Не трогать окно ежа, голос, запись. Не менять хранилище календаря сверх нужного экрану.
