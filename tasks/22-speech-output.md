# 22. Синтез речи: Тишка говорит вслух

## Цель

Реплику `say` Тишка произносит голосом через службу синтеза; рот персонажа двигается по громкости звука. Текст перед синтезом готовится: числа и время — словами, латиница — по-русски. Правила подготовки относятся только к речи: в облачке и в чате текст остаётся как есть.

## Служба синтеза

Внешняя служба, интерфейс задан и не меняется:

- `GET <ttsUrl>/health` → `200`, `{"status":"ok","engine":"…","voice":"…"}`;
- `POST <ttsUrl>/tts`, тело `{"text":"…"}` → `200`, `audio/wav`.

## Изменение контракта

В `docs/contracts.md` в `Config.voice` вместо `ttsEngine` — `tts: { enabled: boolean; url: string; volume: number }` (по умолчанию `enabled: false`, `url: "http://127.0.0.1:8179"`, `volume: 1`). Перенести в типы, значения по умолчанию и разбор настроек; старое поле `ttsEngine` в сохранённых настройках игнорируется.

## Что сделать

### Подготовка текста

`src/voice/speech-text.ts` — чистые функции, без сети:

```ts
function prepareForSpeech(text: string): string;
```

- **Время.** `9:30`, `09.30`, `в 16:00` → «девять часов тридцать минут», «шестнадцать часов ровно»; согласование: «один час», «два часа», «пять часов», «одна минута», «две минуты», «двадцать одна минута».
- **Числа.** Целые до миллиона — словами («23» → «двадцать три»); дробные с запятой или точкой — «три целых пять десятых» для одной цифры после запятой, иначе цифры по одной после слова «запятая»; проценты — «пять процентов» с согласованием; порядковые с окончанием («3-й», «5-го») — числом словами без окончания, это допустимо.
- **Существительное после числа** не склоняется заново — произносится как написано.
- **Даты.** `04.10.2026` и `4 октября` → «четвёртое октября»; год — «две тысячи двадцать шестого года», только если он есть в тексте.
- **Латиница.** Словарь частых слов и названий (расширяемая константа): Confluence → «конфлю́енс» без знака ударения — «конфлюенс», Jira → «джира», Outlook → «аутлук», Exchange → «эксчейндж», email/e-mail → «имейл», online → «онлайн», OK → «окей», Excel, Word, Teams, Zoom, GitHub, API («а-пи-ай»), URL («ю-ар-эл»), PDF («пэ-дэ-эф»), ID («ай-ди»). Незнакомое слово латиницей — побуквенная транслитерация по простым правилам (sh → ш, ch → ч, th → т, остальное по буквам); аббревиатура заглавными до 4 букв — по буквам английского алфавита («ВИ-ПИ-ЭН» для VPN).
- **Не произносится:** ссылки (`http…` → «ссылка»), адреса почты (→ «адрес почты»), разметка (`**`, `#`, обратные кавычки, пункты списков), эмодзи, скобки с содержимым длиннее 40 символов.
- **Знаки.** `№` → «номер», `%` → «процент…», `+` между числами → «плюс», `/` между словами → «или», `&` → «и», длинное тире — пауза (запятая).
- **Паузы.** Несколько пробелов и переводы строк — в одну точку или запятую; текст не длиннее 400 символов: длиннее — обрезается по границе предложения.
- Результат содержит только русские буквы, пробелы и знаки `. , ! ? -`.

### Клиент службы и воспроизведение

- `src/voice/tts-client.ts` (без `electron`, с подменяемым `fetch`): `health()`, `synthesize(text): Promise<{ ok: true; wav: Uint8Array } | { ok: false; error: string }>`; таймаут 15 секунд; ошибки — понятные строки на русском.
- Главный процесс: на событие реплики Тишки (`say`) при `tts.enabled` — подготовка текста, запрос к службе, звук передаётся в окно-питомец. Если служба недоступна, реплика остаётся только текстом, ошибка показывается один раз за запуск («Голос недоступен, говорю текстом»), дальше — тихо, повторная проверка службы раз в минуту.
- `src/renderer/pet/speaker.ts`: воспроизведение WAV через Web Audio, громкость из настроек; во время звука — состояние `talking`, уровень рта: огибающая громкости (окно 50 мс, сглаживание), значение 0–1 в `character.setMouth` около 30 раз в секунду; по окончании рот закрывается и состояние возвращается в прежнее. Расчёт огибающей — чистая функция `envelope(samples, sampleRate, windowMs)` в `src/voice/envelope.ts`.
- Очередь: новая реплика во время речи ставится после текущей; если их накопилось больше двух — старые ожидающие отбрасываются.
- Прерывание: событие начала прослушивания, слово «стоп» и просьба уйти останавливают речь сразу и очищают очередь; метод `stopSpeaking()` доступен главному процессу.
- Пока Тишка говорит, главный процесс сообщает об этом режиму разговора (событие `speak.start` / `speak.end` на шине), чтобы он не слушал сам себя.
- Заготовленные фразы без обращения к модели — константа `src/voice/canned.ts`: приветствие при появлении («Фыр. Слушаю.»), «Думаю…» не произносится, ошибка («Не вышло, смотри карточку»), прощание («Фыр. Я рядом.»). Звук заготовленных фраз запрашивается у службы один раз и хранится в памяти процесса.

### Настройки

Новый раздел `src/renderer/settings/speech-section.ts` (подключить на экране «Голос» под существующим разделом; файл `voice-section.ts` не менять): переключатель «Говорить вслух», адрес службы, громкость, состояние службы (движок и голос из `/health`), кнопка «Сказать пример» — произносит «Привет, я Тишка. Сейчас девять часов тридцать минут.» Кнопки — с откликом через `runWithFeedback`. Раздел возвращает `{ refresh() }`, если так уже устроены соседние разделы.

## Как проверить

Тесты `tests/speech-text.test.ts`:

- «Встреча в 9:30» → «Встреча в девять часов тридцать минут»; «в 16:00» → «в шестнадцать часов ровно»; «21 минута» согласована;
- «Осталось 23 задачи» → «Осталось двадцать три задачи»; «5%» → «пять процентов»; «3,5» → «три целых пять десятых»;
- «Открой Confluence и Jira» → без латиницы; «VPN» → по буквам; незнакомое слово транслитерировано;
- ссылка и адрес почты заменены словами; разметка и эмодзи убраны;
- результат любого теста не содержит цифр и латиницы (проверка регулярным выражением на наборе из 30 разных фраз);
- длинный текст обрезан по границе предложения.

Тесты `tests/tts-client.test.ts`, `tests/envelope.test.ts`: успех, ошибка службы, таймаут; огибающая тишины — нули, синусоиды — около постоянного значения, значения в 0–1. Тест очереди и прерывания на подменном проигрывателе.

`npm run typecheck`, `npm test`, `npm run build`.

Скрипт `scripts/check-tts.ts "<фраза>" [--url …] [--out файл.wav]`: печатает подготовленный текст, время ответа службы и сохраняет звук.

## Не делать

Выбор и установка движка синтеза, запуск службы из приложения, произнесение текста карточек, правки `voice-section.ts`, `vad.ts`, `recorder.ts` (их меняет другая задача).
