# 103. Синхронизация рта с речью и смена эмоции посреди реплики (каркас)

Новый персонаж (задачи 101, 102) умеет формы рта для речи: `m_closed`, `m_teeth`, `m_e`, `m_a`, `m_o`, `m_u`, `m_f`, `m_l`, и наборы эмоций (глаза, брови, рот покоя, эффекты). Сейчас рот идёт по громкости. Нужен каркас, который выдержит замену спрайтов и клипов.

## Что сделать

### Рот

- Модуль `src/voice/lipsync.ts` (чистые функции, без DOM): по тексту части реплики и огибающей громкости её звука строит дорожку форм рта — перенос алгоритма `assets/tishka/model/reference/lipsync.py`: кадры, где звучит голос (громкость выше порога), делятся между буквами текста с весом гласных 1 и согласных 0,6; буква даёт форму (а/я — `m_a`, о/ё — `m_o`, у/ю — `m_u`, э/е/и/ы — `m_e`, м/б/п — `m_closed`, ф/в — `m_f`, л — `m_l`, остальное — `m_teeth`); тихий гласный — `m_teeth`; форма держится не меньше 50 мс. Текст берётся тот, что ушёл в синтез (после подготовки: числа словами), без знаков и латиницы.
- Огибающая считается из WAV, который уже есть в главном процессе перед воспроизведением (`src/main/pet-speak*.ts`, `src/voice/envelope.ts`); дорожка рта передаётся окну ежа вместе со звуком. Воспроизведение в окне (`src/renderer/pet/speaker.ts`) ведёт рот по времени звука (`audio.currentTime`), а не по таймеру: пауза, задержка старта и обрыв не рассинхронизируют рот. Если дорожки нет — прежний режим по громкости.
- Переходник `Character`: необязательный метод `setViseme(shape | null)`; прежний ёж его не реализует и продолжает жить на `setMouth(level)`.

### Эмоции

- Набор эмоций описан данными: в `assets/tishka/model/` добавить `moods.json`, взяв содержимое `MOODS` из `reference/player.html`: имя — глаза, брови, рот покоя, эффекты. Переходник: `setMood(name)`; смена эмоции не прерывает клип и речь — меняются только слои лица и эффекты, рот речи остаётся ведущим, пока идёт звук.
- Эмоция может меняться посреди реплики: в ответе модели допускается разметка `[эмоция]` внутри текста реплики (`say`), например «Сейчас посмотрю. [happy] Нашёл!». Ядро (`src/core/agent/reply.ts`) вырезает метки из текста для показа и озвучки и отдаёт рядом список `moods: [{ at: позиция в знаках очищенного текста, mood }]`; неизвестные имена отбрасываются. Главный процесс переводит позицию в знаках во время по той же раскладке букв, что и рот, и шлёт окну дорожку эмоций вместе со звуком; без звука (ответ текстом) эмоции применяются по мере показа, последняя остаётся до следующего состояния.
- В подсказку модели — одна строка: какие эмоции есть и что метку можно ставить внутри реплики, не чаще одной на предложение. Список эмоций берётся из `moods.json`; при прежнем еже метки вырезаются и ни на что не влияют (остаётся `mood` ответа).

## Как проверить

Тесты: дорожка рта для известной фразы и синтетической огибающей (число смен, формы на гласных, минимальная длительность); рот идёт по времени звука на подставном аудио с паузой; разбор меток эмоций (вырезание, позиции, неизвестные имена, метка в начале и в конце); перевод позиций во время; смена эмоции не прерывает клип; прежний ёж не ломается. Сценарий: ответ с меткой посреди реплики — в ленте и озвучке текста метки нет, окно получило смену эмоции. `npm run typecheck`, `npm run test:scenarios`, `npx vitest run --maxWorkers=1`, `npm run build`. Обновить `docs/contracts.md`.
