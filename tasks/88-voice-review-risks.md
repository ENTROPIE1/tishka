# 88. Три замечания из чтения кода голосового узла

1. Таймер тишины разговора не останавливается на время распознавания фразы (`src/voice/wake-flow.ts`, `handlePhrase`): при медленном распознавании разговор закрывается, пока фраза ещё распознаётся, и она пропадает. Сделать: пока идёт распознавание фразы, сказанной в разговоре, таймер тишины стоит; после результата — заводится заново, если фраза была речью; пустой результат таймер не продлевает (отсчёт продолжается с того места, где остановился).
2. Неуверенно распознанная фраза отбрасывается молча (`src/voice/stt-http.ts`): человек сказал тихо — никакой реакции. Сделать: в разговоре на отброшенную по уверенности фразу (не на пустую и не на шумовую) ёж коротко показывает подписью под собой «не разобрал» на 2 секунды, без облачка, без речи и без сообщения об ошибке; три таких подряд — один раз подсказка про порог и микрофон.
3. Пауза записи теряется, если прослушивание запускается, когда пауза уже действует (`src/renderer/shared/phrase-listener.ts`: `start()` сбрасывает признак паузы). Сделать: запуск сохраняет действующую паузу.

Каждый пункт — сценарием в `tests/scenarios` и тестом модуля. `npm run typecheck`, `npm run test:scenarios`, `npx vitest run --maxWorkers=1`, `npm run build`. Файл `wake-flow.ts` не увеличивать: добавляемое выносить в соседний модуль.
