# Приёмка задачи 115

## Ход работы

Для задачи 115 запускалась фоновая сессия OpenCode на `DKS-Leo-B` под контролем Sol-агента. За более чем два часа и две сессии DKS закрыла геометрию холста, раскладку и большую часть тестов, но не закрыла функциональный блокер в обработчике кликов. Оставшуюся правку внесли вручную в рабочей ветке `task115` по разрешению владельца. `main` и удалённый репозиторий не менялись.

## Найденный блокер и ручная правка

`window`-обработчик `pointerdown` в `src/renderer/pet/pet.ts` начинал перетаскивание по непрозрачному пикселю широкого холста, не исключая элементы строки ввода. В зеркальной раскладке холст перекрывает часть кнопок `mic`, `send` и `settings`; такой клик мог вызвать `preventDefault()` и не дойти до кнопки.

Вручную в `src/renderer/pet/interactivity.ts` добавлена функция `isInteractiveTarget`, распознающая кнопки, поля и вложенные в них элементы. В `pet.ts` эта проверка выполняется до проверки пикселя холста и запуска перетаскивания. В `tests/pet-interactivity.test.ts` добавлены проверки функции для кнопки, вложенного SVG, поля ввода и обычного элемента. Пиксельную проверку холста ранее реализовала DKS.

## Проверки

После ручной правки выполнены успешно:

- `npm run typecheck`;
- `npx vitest run --maxWorkers=1` — 211 файлов, 1570 тестов;
- `npm run test:scenarios` — 22 файла, 68 тестов;
- `npm run build`;
- `git diff --check`;
- целевые тесты интерактивности, геометрии и раскладки — 4 файла, 42 теста.

После ручной правки проверка выполнена в локальном Electron-стенде с удалённой отладкой: Тишка загрузился, клипы `talk`, `happy`, `confused`, `kick` выбрались и проигрывались без ошибки. В настоящем окне персонажа проверены обычная и зеркальная раскладки: ноги накладываются на строку ввода, кнопки `mic`, `send` и `settings` видимы. Реальные клики по этим кнопкам в обеих раскладках прошли; окно настроек открылось. Прозрачная точка холста не запускала перетаскивание, непрозрачная точка обрабатывалась как персонаж. Визуальная проверка выполнена основным агентом.

## Состояние

Изменения находятся в ветке `task115`, не закоммичены и не слиты. `main` остаётся без изменений. Отчёт фиксирует, что DKS не завершила задачу за два часа, а оставшаяся функциональная правка, автоматические проверки и визуальная проверка выполнены основным агентом по разрешению владельца. Приёмка задачи завершена; следующий шаг — показать diff и отдельно согласовать коммит и слияние.
