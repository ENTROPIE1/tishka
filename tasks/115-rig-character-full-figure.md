# 115. Новый Тишка виден целиком и стоит на строке ввода

Находка владельца 6 октября: когда новый Тишка машет руками, руки обрезаются сбоку.

## Причина (проверено)

- Место под персонажа в окне ежа считается по туловищу: 520 единиц модели, при высоте 260 точек это 111 точек (`src/pet/character-size.ts`). Холст проигрывателя (`.character .rig-canvas`) ровно такой же ширины, всё за ним не рисуется.
- Замер на стенде по всем клипам (границы непрозрачных пикселей, единицы модели, ось персонажа x = 400): покой 132–656, разговор 132–790, радость 22–766, растерянность 132–839, удар ногой −27–839, по вертикали 32–1178 (уведомление до −5). Нужна ширина около 880 единиц (±440 от оси) — примерно 190 точек при высоте 260.
- Справа от персонажа до края окна 16 точек, рука уходит вправо примерно на 40 — даже широкий холст обрежется краем окна.

## Что сделать

- Холст нового персонажа шире места в раскладке: 880 единиц модели по ширине (±440 от оси), по высоте с запасом сверху на эффекты. Холст лежит поверх соседних частей окна (`position: absolute`, выше облачка и строки ввода по слоям), раскладку не раздвигает. Числа запаса — константы рядом с размерами модели в `src/pet/character-size.ts`. Проигрыватель (`rig-player.ts`) рисует модель так, чтобы ось персонажа была по центру холста, а высота фигуры осталась 260 точек.
- Окно ежа: справа от места персонажа запас под руку (в `petLayout` — отдельный правый отступ для нового персонажа, не меньше половины лишней ширины холста), чтобы рука не упиралась в край окна и экрана. Прежний ёж не меняется.
- Тишка стоит на строке ввода с наложением: ноги опускаются на строку ввода, персонаж нарисован поверх её рамки. Строка ввода справа короче на ширину ног, кнопки «Отправить» и «Настройки» остаются видны и нажимаются (решение владельца). Подпись состояния под персонажем не перекрывает строку.
- Щелчки по прозрачным местам холста (вокруг рук, между ног) проходят сквозь окно и к строке ввода, как сейчас у прежнего ежа: попадание считать по непрозрачности пикселя холста в точке курсора, а не по прямоугольнику элемента (`hitTestRegions` в `src/renderer/pet/interactivity.ts`). Перетаскивание за самого персонажа работает как сейчас.
- Зеркальная раскладка (колонка справа от персонажа) — всё то же с другой стороны.

## Как проверить

Тесты: размеры холста и запасов из констант; раскладка окна с новым персонажем оставляет справа запас под руку и не выходит за экран, в зеркальной — слева; строка ввода короче на ширину ног, кнопки внутри видимой части; попадание по прозрачному пикселю холста не делает окно ловящим мышь, по непрозрачному — делает (jsdom с подставным холстом); прежний ёж: раскладка и размеры без изменений. Проверка глазами на стенде и в окне ежа: клипы «разговор», «радость», «растерянность», «удар ногой» не обрезаются ни краем холста, ни краем окна. `npm run typecheck`, `npm run test:scenarios`, `npx vitest run --maxWorkers=1` (по одной, память ограничена), `npm run build`.

## Не делать

Не трогать запись, распознавание, разговор (`src/voice`). Не менять клипы и файлы модели. Создаваемые файлы не длиннее 200 строк.
