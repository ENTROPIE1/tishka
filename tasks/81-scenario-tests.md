# 81. Сценарные тесты ежа и голоса

Правки окна ежа, состояний, разговора и речи проходят свои тесты, но ломают соседнее поведение: ошибки находятся на стыках. Нужен набор тестов, которые прогоняют цепочки действий пользователя через настоящие модули вместе и проверяют то, что видит человек.

## Что сделать

- Стенд сценариев `tests/scenarios/harness.ts`: собирает вместе настоящие модель состояний ежа (`src/pet/state.ts`), жизненный цикл окна (`src/main/pet-lifecycle.ts`), переключение разговора (`src/voice/wake-flow.ts` и соседние модули), речь (`src/main/pet-speak.ts`) на общей шине событий. Подставными остаются только края: окно Electron, служба распознавания (управляемое состояние «выключена / запускается / готова / упала» и заданный текст ответа), служба синтеза (успех, отказ на тексте, недоступна), ядро (заданный ответ), часы (управляемое время).
- Стенд даёт действия человека: запуск приложения, вызов клавишей, вызов по имени, щелчок по значку, щелчок по микрофону, произнесённая фраза, шум (пустое распознавание), печать в строке, отправка текста из строки ежа, отправка текста из окна чата, нажатие и отпускание ежа мышью, ход времени. И наблюдения: виден ли ёж, состояние и подпись, текст облачка, что произнесено, включён ли значок микрофона, идёт ли запись, принимает ли строка ввода щелчки, какие сообщения об ошибках показаны.
- Сценарии в `tests/scenarios/*.test.ts`, по одному файлу на тему, каждый сценарий — понятное имя на русском и ссылка на номер дефекта в комментарии. Обязательные:
  1. Запуск при запускающейся службе: ёж виден сразу, строка работает, приветствие нейтральное, значок в ожидании; служба готова → запись включилась один раз, облачко «Слушаю…» только после приветствия (Д17, Д22).
  2. Запуск при готовой службе: приветствие и облачко совпадают дословно (Д22).
  3. Вызов клавишей, по имени, щелчком по значку: одно и то же появление на месте, строка ввода принимает щелчки (Д9, Д10).
  4. «Тишка, уходи» и «можешь быть свободен»: ответ показан и произнесён, затем уход и скрытие за секунды; при недоступной речи — то же; пока ёж виден, строка работает (Д16).
  5. После ухода: вызов по имени и клавишей работает, запись включается (Д4).
  6. Щелчок по микрофону: выключил → включил → выключил, значок каждый раз соответствует записи; после выключения щелчком автоматическое включение в том же появлении не происходит (Д20).
  7. Печать в строке при включённом разговоре: запись на паузе, ошибок нет, через 2 секунды запись возобновляется (Д19).
  8. Шум вместо речи в разговоре: ни облачка с ошибкой, ни речи; тишина не продлевает разговор (Д19).
  9. Нажатие и удержание ежа мышью: запись на паузе, фраза за это время не уходит на распознавание (Д21).
  10. Реплика из окна чата: скрытый ёж не появляется, видимый не показывает облачко и карточку (Д8).
  11. Сбой синтеза на одной реплике: она показана текстом, следующая звучит; недоступная служба — одно сообщение, восстановление без действий человека (Д18).
  12. Уведомление от навыка: ёж появляется, «Слушаю» не звучит, по имени после этого откликается (задача 62).
  13. Тишина в разговоре дольше срока: ёж предупреждает видом и уходит; до ухода строка работает.
- Сценарий, который не проходит на текущем коде, не ослаблять и не удалять: пометить `it.fails` с комментарием, что именно расходится, и перечислить такие в отчёте — это найденные дефекты.
- Команда `npm run test:scenarios` в `package.json` (только каталог сценариев). В `AGENTS.md` правило: любая правка окна ежа, состояний, разговора, микрофона или речи заканчивается прогоном сценариев; новый дефект в этой области сначала добавляется сценарием.

## Как проверить

`npm run typecheck`, `npm run test:scenarios`, `npx vitest run --maxWorkers=2`, `npm run build`. В отчёте: список сценариев, какие проходят, какие помечены `it.fails` и почему.

## Не делать

Не менять код продукта (`src/`), кроме случая, когда модуль невозможно собрать в стенде без малой правки экспорта — такую правку описать в отчёте. Не подменять модели состояний и разговора подставными. Файлы не длиннее 200 строк, стенд при необходимости разбить на несколько модулей.
