# 102. Выбор персонажа в настройках: «Первый ёж» и «Тишка»

После задачи 101 есть проигрыватель костной модели (`src/renderer/character-rig/`). Подключить его как второго персонажа через существующий переходник `Character` (`src/renderer/pet/character.ts`, `character-factory.ts`).

## Что сделать

- Настройка `persona.character`: `hedgehog` (прежний, по умолчанию) или `tishka`. Экран «Характер»: блок «Внешность» с двумя карточками-переключателями и уменьшенным изображением каждого; применяется сразу, без перезапуска: окно ежа пересоздаёт персонажа.
- `RigCharacter` — реализация `Character` поверх проигрывателя: `setClip` (имена клипов совпадают; клипы, которых нет в модели, заменяются на `idle`), `setFlip`, `setMouth(level)` — пока по громкости: тише 0,15 — рот покоя, до 0,45 — `m_teeth`, выше — `m_a` (как режим «громкость» в образце), `dispose` останавливает цикл кадров и освобождает картинки.
- Размер и место: новый персонаж высокий (примерно 520×1220 в единицах модели), прежний — квадратный. Переходник сообщает свои пропорции; раскладка окна ежа (`src/pet/layout.ts`, `src/renderer/pet/layout-view.ts`) учитывает их: персонаж стоит ногами на той же линии, облачко и карточка не перекрывают лицо, строка ввода на месте, окно не выходит за экран. Высота нового персонажа на экране — константа в коде, по умолчанию 260 точек.
- Щелчки по прозрачным областям вокруг персонажа проходят сквозь окно, как сейчас (`interactivity.ts`): для нового персонажа — по маскам слоёв или по прямоугольнику фигуры.
- Если модель не загрузилась (нет файлов) — прежний ёж и строка в журнале времени, приложение не падает.
- Сборка: файлы модели попадают в собранное приложение; путь без кириллицы.

## Как проверить

Тесты: настройка сохраняется и читается, старые настройки без поля — `hedgehog`; смена персонажа пересоздаёт его без перезапуска; `RigCharacter` на подставном проигрывателе: клипы, отражение, рот по громкости, запасной клип; раскладка с высоким персонажем не выходит за экран и не перекрывает облачком лицо; при отсутствии модели — прежний ёж. Сценарий в `tests/scenarios`: запуск с `tishka` — персонаж появляется, состояния сменяют клипы. `npm run typecheck`, `npm run test:scenarios`, `npx vitest run --maxWorkers=1`, `npm run build`. Обновить `docs/contracts.md`.

## Не делать

Не трогать запись, распознавание, разговор (`src/voice`, `wake-listener.ts`). Создаваемые файлы не длиннее 200 строк.
