# 111. Счётчик выполненных дел

Человеку и зрителю показа нужно видеть, сколько рутины Тишка снял. Нужен счётчик выполненных дел.

## Что сделать

- Ядро (`src/core/stats/`, модули не длиннее 200 строк): файл `stats.json` в каталоге данных. Учитывается: выполненный навык (название, время, длительность, сколько шагов), сработавшая автоматизация, созданный черновик письма, найденная страница или письмо, занесённое событие календаря (если календарь есть), напоминание. Для навыка хранится оценка «сколько минут это занимает руками» (`manualMinutes`, по умолчанию 5; задаётся в карточке навыка и голосом при обучении, если человек сказал).
- Сводка: за сегодня, за неделю, за всё время — число дел и сэкономленные минуты; разбивка по навыкам.
- Экран: блок на главном экране основного окна «Сегодня Тишка сделал N дел и сберёг около M минут» и страница «Сделано» в боковом меню с разбивкой по дням недели (простые столбики без сторонних библиотек) и списком последних дел.
- Инструмент `stats_summary` и правило в подсказке: «что ты сегодня сделал», «сколько времени ты мне сэкономил» — короткий ответ вслух и карточка.
- Повреждённый файл не роняет ядро. Запись атомарная.

## Как проверить

Тесты: учёт каждого вида дела, сводка по периодам с подставным временем, оценка минут из карточки навыка, повреждённый файл, экран (jsdom) показывает числа и обновляется при событии ядра, инструмент. `npm run typecheck`, `npx vitest run --maxWorkers=1` (проверки по одной, память машины ограничена), `npm run build`. Обновить `docs/contracts.md` и `README.md`.

## Не делать

Не трогать окно ежа, голос, запись.
