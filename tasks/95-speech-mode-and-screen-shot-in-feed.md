# 95. Переключение «голосом / текстом» по просьбе и снимок экрана в ленте

## 1. Тишка сам переключает, отвечать вслух или только текстом

- Новый инструмент ядра `speech_mode` с параметром `mode`: `voice` (отвечать вслух и текстом) или `text` (только текстом). Меняет настройку `voice.tts.enabled`, сохраняет её и применяет сразу, без перезапуска; экран «Голос» показывает новое значение. При переходе на текст звучащая речь останавливается, само подтверждение вслух не произносится. При переходе на голос подтверждение звучит.
- Вызывается по явной просьбе: «говори голосом», «отвечай вслух», «озвучивай», «пиши текстом», «не говори вслух», «помолчи», «без звука». Короткое подтверждение в тоне Тишки («Хорошо, пишу молча», «Хорошо, говорю вслух»).
- Тишка знает свой режим: в системную подсказку каждого хода добавляется строка о текущем режиме ответа (вслух или только текстом) и о том, как пришла реплика человека — голосом или текстом (источник есть в `src/main/source-bus.ts`; до ядра довести отдельным необязательным параметром, не ломая существующие вызовы). На вопрос «ты сейчас говоришь или пишешь?» он отвечает верно.
- Если служба синтеза недоступна, переход на голос отвечает честно: «Голос сейчас недоступен, пишу текстом», настройка при этом включается.

## 2. Снимок экрана остаётся в ленте

- `screen_look` (разбор экрана) сохраняет снимок в каталог снимков так же, как `screen_shot` (`src/core/tools/screen.ts`), с тем же ограничением числа файлов.
- Ответ на просьбу посмотреть на экран показывается в ленте чата вместе с уменьшенным снимком над текстом ответа; щелчок открывает снимок в полном размере (как у карточки вида `image`). Это работает и для прямого ответа (`answer_directly`), и когда ответ дописывает основная модель; если модель сама показала другую карточку, снимок добавляется отдельной строкой ленты перед ответом.
- Снимок попадает в историю (`history.jsonl`) ссылкой на файл и восстанавливается при перечитывании ленты и после перезапуска. Если файл уже удалён ограничением числа снимков, на его месте приглушённая строка «Снимок экрана удалён».
- В облачке и карточке ежа снимок не показывается: только в ленте чата. В контекст модели картинка повторно не отправляется.

## Как проверить

Тесты: инструмент меняет настройку и она действует на следующую реплику без перезапуска; переход на текст останавливает речь; строка о режиме и о способе реплики есть в подсказке; `screen_look` сохраняет файл и соблюдает предел; лента показывает снимок, история его хранит и восстанавливает; удалённый файл даёт строку-заглушку. `npm run typecheck`, `npm run test:scenarios`, `npx vitest run --maxWorkers=1` (проверки по одной, память машины ограничена), `npm run build`. Обновить `docs/contracts.md`.

## Не делать

Не трогать запись и распознавание (`src/voice/wake-flow.ts`, `src/voice/vad.ts`, `src/renderer/shared/phrase-listener.ts`), окно ежа сверх сказанного. Создаваемые файлы не длиннее 200 строк.
