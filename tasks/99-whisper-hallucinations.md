# 99. Распознавание выдумывает «Субтитры создавал DimaTorzok» и «Продолжение следует…»

На тишине, шуме и обрывках речи модель Whisper возвращает фразы из титров, на которых она училась. Они приходят Тишке как реплика человека, он на них отвечает, они остаются в истории. В истории за вечер 5 октября: «Субтитры создавал DimaTorzok» дважды, «Продолжение следует...» один раз.

## Что сделать

1. В `src/voice/stt-http.ts` (или соседнем модуле не длиннее 200 строк) — отсев известных выдумок: расшифровка, которая целиком (без учёта регистра, знаков препинания, «ё/е» и пробелов по краям) совпадает с фразой из списка или состоит только из таких фраз, считается шумом — результат как у пустой расшифровки (`empty: true`), человеку и ядру не показывается. Список отдельной константой с комментарием об источнике:
   - «Субтитры создавал DimaTorzok», «Субтитры сделал DimaTorzok», «Субтитры делал DimaTorzok», любые «Субтитры … DimaTorzok»;
   - «Редактор субтитров …», «Корректор …» (титры вида «Редактор субтитров А.Семкин Корректор А.Егорова»);
   - «Продолжение следует», «Спасибо за просмотр», «Спасибо за внимание» как единственное содержимое фразы, «Подписывайтесь на канал», «Ставьте лайки», «Всем пока» как единственное содержимое при длительности записи меньше двух секунд;
   - «Субтитры подогнал …», «Добавил субтитры …», «Amara.org», одиночные «Угу», «Ага» не трогать — это может быть речь.
   Если такая фраза стоит в начале или в конце расшифровки вместе с настоящими словами — вырезать её, остальное оставить.
2. В запрос к службе добавить параметры, уменьшающие выдумки, если служба whisper.cpp их принимает (проверить по её справке и на деле не ломать): порог отсутствия речи, запрет подсказки-продолжения из предыдущего текста. Подсказка с именем (`wakePrompt`) остаётся.
3. Отброшенная выдумка пишется в журнал времени: `stt.request.end ok=false reason=hallucination`.

## Как проверить

Тесты: каждая фраза списка в разных регистрах и с разной пунктуацией отсеивается; фраза с настоящими словами вокруг очищается и проходит; «Спасибо за внимание, отправь отчёт Ане» проходит целиком; обычная речь не затронута. Сценарий в `tests/scenarios`: служба вернула «Субтитры создавал DimaTorzok» в разговоре — в ядро ничего не ушло, разговор продолжается. `npm run typecheck`, `npm run test:scenarios`, `npx vitest run --maxWorkers=1` (проверки по одной), `npm run build`.
