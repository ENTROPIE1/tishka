# 114. Мелочи из чтения изменений за ночь (Н40, Н41, Н42, Н44)

Четыре небольших исправления, каждое со своим тестом.

1. **Стенд, размытый персонаж (Н40).** `src/renderer/character-rig/rig-player.ts`: при изменении размера контейнера (ползунок масштаба на стенде, смена размера окна) холст пересчитывает свой размер в пикселях устройства; наблюдать за контейнером через `ResizeObserver` (если есть), иначе пересчитывать раз в кадр по сравнению с прошлыми размерами. Сборка: в `electron.vite.config.ts` в собранное приложение копируется только `assets/tishka/model` без подпапки `reference` (справочный проигрыватель и скрипт на Python в приложении не нужны).
2. **Отсев выдумок (Н41).** `src/voice/stt-hallucination.ts`: одиночная фраза «спасибо за внимание» выдумкой не считается (человек так говорит); «корректор» и «редактор субтитров» вырезаются только вместе с идущими следом словами с заглавной буквы (имена), а не любыми тремя словами. `src/voice/stt-service.ts`: справка программы распознавания читается не синхронно при запуске, а асинхронно (`spawn` с таймаутом 5 с), чтобы зависшая программа не останавливала главный процесс.
3. **Имя модели в ошибке (Н42).** `src/core/agent/agent.ts`: когда отказала модель картинок, сообщение называет её (`llm.visionModel`), а не основную. Ошибка шлюза должна нести имя модели, на которую шёл запрос (`LlmError.model`), агент берёт его оттуда.
4. **Подсказка о калибровке (Н44).** `src/voice/missed-speech.ts`: отброшенная выдумка распознавания (`reason: hallucination` в результате или отдельный признак `hallucination: true` в `TranscribeResult`) промахом не считается — подсказка о калибровке на неё не срабатывает.

## Как проверить

Тесты на каждое: смена размера контейнера меняет размер холста (jsdom с подставным `ResizeObserver`); «спасибо за внимание» проходит, «Субтитры создавал DimaTorzok» по-прежнему отбрасывается, «Корректор Иванова» вырезается, «корректор прислал правки» — нет; справка читается асинхронно и зависание не блокирует (подставной `spawn`); ошибка модели картинок называет её имя; выдумка не считается промахом. `npm run typecheck`, `npm run test:scenarios`, `npx vitest run --maxWorkers=1` (по одной, память ограничена), `npm run build`.

## Не делать

Не менять пороги, правило времени, тексты реплик. Файлы не длиннее 200 строк.
