# 75. При запуске ёж говорит «Слушаю», а микрофон не включён

Шаги: ключ шлюза задан, запустить приложение. Ёж появляется и приветствует («Фыр, слушаю»), но микрофон у строки ввода выключен, запись не идёт. Ожидание: при появлении ежа по запуску разговор включается сам, как при вызове по имени (настройка `voice.talkByDefault`).

## Вероятная причина (проверить)

`openPet` при запуске (`src/main/index.ts`) вызывает `pet.wake('click')` сразу. В `src/main/pet-listen.ts` включение записи требует `stt.status() === 'ready'`, а служба распознавания в этот момент ещё запускается, поэтому запись не стартует (или появляется ошибка «Распознавание речи не настроено»), и повторной попытки нет.

## Что сделать

- Появление ежа при запуске не ждёт службу: ёж показывается сразу, строка ввода работает сразу.
- Если `talkByDefault` включён, микрофон и распознавание настроены: как только служба распознавания стала готова, запись включается сама, один раз за это появление — при условии, что ёж ещё на экране, человек сам не выключил микрофон значком и не идёт ответ. Если служба не поднялась (ошибка или тайм-аут) — запись не включается, ёж остаётся с текстовой строкой, без повторяющихся сообщений об ошибке.
- Пока служба не готова, у микрофона в строке ввода видно состояние ожидания (существующими средствами: подпись состояния или вид кнопки), а не выключенный без объяснения значок.
- Приветствие не должно обещать того, чего нет: слово «слушаю» и состояние «слушает» — только когда запись действительно идёт. До готовности — нейтральное приветствие.
- То же правило для любого вызова ежа в момент, когда служба ещё запускается (клавиша, значок): не ошибка «не настроено», а ожидание готовности и включение записи. Ошибка «не настроено» — только когда служба выключена или упала.

## Как проверить

Тесты: вызов при статусе службы «запускается» → запись не начата, ошибки нет; переход службы в «готова» → запись включается один раз; ёж ушёл до готовности → запись не включается; человек выключил микрофон до готовности → не включается; служба упала → не включается, одна запись об ошибке. `npm run typecheck`, `npx vitest run --maxWorkers=2`, `npm run build`.

## Не делать

Не задерживать показ ежа и строки ввода. Не менять запуск самой службы распознавания (`src/voice/stt-service.ts`) сверх чтения её состояния или подписки на него. Не трогать правила задач 68–70. Файлы не длиннее 200 строк.
