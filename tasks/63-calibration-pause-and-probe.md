# 63. Калибровка при включённом разговоре в чате; проверка службы без предела времени

Находки 5, 7, 8 из `tasks/reports/54-voice.md`.

## Что сделать

- `src/renderer/chat/talk-mode.ts`: слушатель микрофона чата работает только когда `state.conversation && state.active`. На время калибровки (`active: false`) слушатель останавливается, после — запускается снова, значок остаётся включённым. `src/main/chat-talk.ts`: фразы, пришедшие во время паузы, отбрасываются.
- `src/voice/stt-http.ts`, `probe`: запрос с пределом времени 3 секунды (`AbortSignal`), таймер снимается в `finally`. `src/voice/stt-service.ts`: общий срок ожидания готовности 30 секунд выдерживается, даже если один запрос завис.
- `src/main/ipc-voice.ts`: если запуск службы вытеснен новым запуском («Запуск отменён»), обработчик не возвращает эту ошибку, а дожидается результата нового запуска и возвращает его.

## Как проверить

Тесты: пауза останавливает и возобновляет слушатель чата; фраза во время паузы не доходит до ядра; `probe` завершается по сроку при зависшем запросе; готовность за 30 секунд при зависающем `probe`; два запуска подряд — оба вызова получают итог второго.

`npm run typecheck`, `npx vitest run --maxWorkers=2`, `npm run build`.
