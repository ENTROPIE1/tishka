# 83. Два дефекта, найденные сценарными тестами

Оба зафиксированы сценариями с пометкой `it.fails` в `tests/scenarios`.

## 1. «Можешь быть свободен» не отпускает ежа

`isDismiss` в `src/voice/wake.ts` сверяет фразу целиком со списком, поэтому «можешь быть свободен», «всё хорошо, можешь пока быть свободен», «ты свободен», «пока иди» уходят в ядро как обычный вопрос: ёж отвечает, но не уходит.

Что сделать: распознавать просьбу уйти по смыслу фразы, а не по точному совпадению — набор ключевых оборотов («уходи», «уйди», «свободен», «можешь идти», «можешь быть свободен», «иди отдыхай», «пока не нужен», «спрячься», «скройся») с допуском вводных слов до и после и имени; при этом отрицания и вопросы не считаются просьбой («не уходи», «ты свободен завтра?», «когда я буду свободен»), и длинная фраза по делу с таким словом внутри тоже нет (порог длины). Список оборотов — константа в одном месте.

## 2. Озвучка ответа из окна чата поднимает скрытого ежа

Реплика из окна чата: сам ответ скрытого ежа не поднимает (задача 68), но озвучка приходит позже, когда `src/main/source-bus.ts` уже сбросил источник на «ёж», и событие `speak.start` в `src/pet/state.ts` показывает ежа.

Что сделать: источник реплики должен сопровождать и её озвучку — событие начала речи несёт источник той реплики, которую озвучивает, а не текущее значение шины. Скрытый ёж на озвучку реплики из чата не появляется; видимый — говорит без облачка и карточки, как сейчас.

## Как проверить

Снять `it.fails` с обоих сценариев — они должны проходить. Добавить тесты `isDismiss` на перечисленные фразы и на исключения. `npm run typecheck`, `npm run test:scenarios`, `npx vitest run --maxWorkers=2`, `npm run build`.

## Не делать

Не менять тексты ответов. Не трогать включение записи и паузу прослушивания.
