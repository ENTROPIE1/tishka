# 87. Быстрый отклик на имя и порог громкости ползунком

По журналу времени: человек позвал «Тишка» — ёж пришёл через 17 секунд. Запись фразы не заканчивалась 12 секунд (фоновый звук не даёт детектору увидеть тишину), затем 5 секунд распознавания.

## Что сделать

### Порог громкости (решение тестировщика)

- Порог задаётся числом в настройках (`voice.mic.threshold`) и не подстраивается сам: звук тише порога не считается звуком — не начинает запись и считается тишиной для конца фразы. Автоматическая подстройка под шум в `src/voice/vad.ts` убирается; если порог не задан — значение по умолчанию для тихой комнаты (константа).
- Экран «Голос» → «Микрофон»: ползунок порога рядом с живой полоской уровня микрофона, на полоске видна черта порога. Изменение применяется сразу, без перезапуска. Выпадающий список чувствительности убирается из интерфейса; поле `sensitivity` в настройках остаётся читаемым для совместимости, но на порог не влияет.
- Калибровка остаётся кнопкой-помощником: измеряет шум и речь и ставит ползунок, значение потом можно подвинуть. «Сбросить калибровку» возвращает значение по умолчанию.

### Прослушивание имени короткими отрезками

- Когда разговор выключен (ёж слушает только имя), фраза не ждёт тишины дольше предела: отрезок не длиннее 4 секунд отправляется на распознавание, запись продолжается следующим отрезком с перекрытием 0,5 секунды, чтобы имя на стыке не потерялось.
- В разговоре предел длины реплики остаётся прежним.
- Если три фразы подряд упёрлись в предел длины, один раз за запуск показывается подсказка поднять порог (ссылка на экран «Голос»).

## Как проверить

Тесты: звук ниже порога не начинает фразу и завершает её; порог не меняется от фонового шума; ползунок сохраняет значение и оно доходит до записи без перезапуска; при выключенном разговоре длинный звук режется на отрезки по 4 секунды с перекрытием; сценарий в `tests/scenarios`: имя, сказанное на фоне непрерывного шума выше порога, распознаётся не позже чем через один отрезок. `npm run typecheck`, `npm run test:scenarios`, `npx vitest run --maxWorkers=1`, `npm run build`.

## Не делать

Не менять паузу записи при печати и перетаскивании, отсев ненадёжного распознавания. Создаваемые файлы не длиннее 200 строк.
