# 58. Настройки действуют без перезапуска

Находки 1 и 2 из `tasks/reports/54-core.md` (там же тесты).

## Что сделать

- Переключатели `web.enabled` и `screen.enabled`: после сохранения настроек инструменты чтения страниц и снимка экрана сразу недоступны модели (нет в списке инструментов) и не выполняются, если их всё же вызвали; после включения — снова доступны. Без перезапуска приложения.
- Адрес шлюза `llm.baseUrl` и модель для картинок `llm.visionModel` читаются при каждом запросе, а не запоминаются при старте (как уже сделано для имени основной модели).
- Просмотреть остальные поля настроек, которые ядро запоминает при старте, и перечислить в отчёте, какие ещё требуют перезапуска (исправлять только названные выше).

## Как проверить

Тесты из отчёта (перенести в `tests/`), плюс: включение обратно возвращает инструмент; смена `visionModel` видна в следующем запросе.

`npm run typecheck`, `npx vitest run --maxWorkers=2`, `npm run build`.

## Не делать

Не трогать `src/renderer`, `src/main`, `src/core/agent`, `src/core/mcp`, `src/core/skills`, `src/core/triggers`. В `src/core/app.ts` менять только создание клиента модели, зрения и регистрацию инструментов. Файлы не длиннее 200 строк.
