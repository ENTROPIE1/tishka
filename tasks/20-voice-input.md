# 20. Голосовой ввод: запись фразы и распознавание

## Цель

Тишку можно позвать горячей клавишей и сказать фразу голосом: приложение записывает речь до паузы, распознаёт её локальной службой и передаёт текст в ядро так же, как набранный с клавиатуры.

Объединяет запись фразы и распознавание (строки 20 и 21 плана).

## Изменение контракта

В `docs/contracts.md` поле `Config.voice` дополнено:

```ts
voice: {
  hotkey: string;
  wakeWords: string[];
  sttUrl: string;                      // адрес службы распознавания
  stt: { exe: string; model: string; audioCtx: number; threads: number };   // автозапуск службы; пустой exe — не запускать
  ttsEngine: 'piper' | 'silero' | 'none';
}
```

Значения по умолчанию: `sttUrl: "http://127.0.0.1:8178"`, `stt: { exe: "", model: "", audioCtx: 768, threads: 4 }`. Перенести в типы, `defaultConfig` и `mergeConfig`.

## Что сделать

### Служба распознавания

`src/voice/stt-service.ts` — без `electron`:

```ts
function createSttService(opts: {
  getConfig: () => Config['voice'];
  spawn?: typeof import('node:child_process').spawn;   // для тестов
  fetch?: typeof fetch;
}): {
  start(): Promise<{ ok: boolean; error?: string }>;   // запускает whisper-server, если задан exe, и ждёт готовности до 30 секунд
  stop(): void;
  transcribe(wav: Uint8Array): Promise<{ ok: true; text: string } | { ok: false; error: string }>;
  status(): 'off' | 'starting' | 'ready' | 'error';
};
```

- Запуск: `<exe> -m <model> -l ru -t <threads> -ac <audioCtx> --host 127.0.0.1 --port <порт из sttUrl>`. Рабочий каталог — каталог программы.
- Путь к программе или модели с символами не из ASCII — ошибка «Путь к службе распознавания должен быть без кириллицы» без попытки запуска: с такими путями служба падает.
- Готовность — успешный ответ на `GET <sttUrl>/`.
- Если `exe` пуст, служба не запускается, но `transcribe` работает с уже запущенной по адресу `sttUrl`.
- `transcribe`: `POST <sttUrl>/inference`, форма с полями `file` (WAV) и `response_format=json`; ответ `{ "text": "..." }`. Текст очищается: пробелы по краям, переводы строк заменяются пробелами, пометки в квадратных и круглых скобках (`[музыка]`, `(смех)`) удаляются. Пустой текст — ошибка «Не расслышал».
- Таймаут запроса 30 секунд. Ошибки — понятные строки на русском.
- При выходе из приложения запущенная служба останавливается по идентификатору процесса.

### Запись

`src/voice/wav.ts` — `encodeWav(samples: Float32Array, sampleRate: number): Uint8Array` — WAV 16 бит, моно. `resample(samples: Float32Array, from: number, to: number): Float32Array` — линейная интерполяция до 16 000 Гц.

`src/voice/vad.ts` — определение конца фразы, чистая логика:

```ts
function createVad(opts?: { silenceMs?: number; maxMs?: number; minSpeechMs?: number }): {
  push(frame: Float32Array, frameMs: number): 'continue' | 'end' | 'timeout' | 'nospeech';
  level(): number;      // 0..1, для индикатора
};
```

- Порог речи подстраивается под шум: уровень шума оценивается по первым 300 мс, речь — уровень заметно выше шума.
- `end` — после речи тишина не меньше `silenceMs` (по умолчанию 1200).
- `timeout` — запись длится `maxMs` (по умолчанию 15 000).
- `nospeech` — за 5 секунд речь так и не началась.

`src/renderer/pet/recorder.ts` — запись с микрофона в окне-питомце (`getUserMedia`, `AudioWorklet` или `ScriptProcessor`), кадры идут в `createVad`; по окончании звук пересчитывается в 16 000 Гц, кодируется в WAV и уходит в главный процесс.

### Связка

- Горячая клавиша (`Config.voice.hotkey`) или значок микрофона рядом с полем ввода в окне-питомце начинают запись: события `wake`, `listen.start`.
- Во время записи в облачке показывается «Слушаю…» и полоска уровня звука.
- Конец записи: звук уходит в `transcribe`; при успехе текст передаётся в `core.handleUserText` (событие `listen.end` отправляет ядро). При ошибке или `nospeech` — событие `error` с текстом и состояние `confused`; поле ввода остаётся для набора текста.
- Повторное нажатие горячей клавиши во время записи завершает запись сразу, Esc отменяет её.
- Если служба не готова, запись не начинается, в облачке — «Распознавание речи не настроено», поле ввода текста работает.
- В окне подключений в разделе «Голос»: горячая клавиша, путь к программе распознавания, путь к модели, состояние службы и кнопка «Проверить» (перезапуск службы и показ состояния).

## Как проверить

Тесты `tests/stt-service.test.ts`, `tests/wav.test.ts`, `tests/vad.test.ts` с подменой `spawn` и `fetch`:

- `start` запускает программу с ожидаемыми аргументами и становится `ready` после успешного ответа службы.
- Путь с кириллицей → ошибка, `spawn` не вызывался.
- Служба не ответила за отведённое время → `error`, процесс остановлен.
- `transcribe` отправляет форму с файлом и возвращает очищенный текст; `" [музыка]  Тишка,\n привет "` → `"Тишка, привет"`.
- Пустой ответ → ошибка «Не расслышал». Сбой сети → понятная ошибка.
- `encodeWav`: правильный заголовок (RIFF, WAVE, 16 бит, моно, частота), длина данных.
- `resample` 48 000 → 16 000 даёт треть отсчётов.
- `createVad`: тишина 5 секунд → `nospeech`; речь, затем 1,2 секунды тишины → `end`; непрерывная речь 15 секунд → `timeout`; короткий щелчок речью не считается.

Проверка вручную: служба `whisper-server` запущена отдельно; `npx tsx scripts/check-stt.ts <файл.wav>` печатает распознанный текст и время. Скрипт `scripts/check-stt.ts` входит в задачу: адрес службы из аргумента `--url`, по умолчанию из настроек по умолчанию.

## Не делать

Вызов по имени, синтез речи, выбор микрофона из списка.
