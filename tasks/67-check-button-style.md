# 67. Кнопка «Проверить» в разделе «Модель» не выглядит кнопкой

## Что сделать

- В разделе «Модель» («Подключения») кнопка «Проверить» оформлена так же, как соседняя «Сохранить»: та же форма, высота, отступы, шрифт, реакция на наведение и нажатие. Различаются только цветом: «Сохранить» — основная, «Проверить» — второстепенная (контур или приглушённая заливка), но явно кнопка.
- Пройти по остальным разделам настроек («Голос», «Память», «Характер», «Приложение», подключения): все кнопки действий одного уровня оформлены единообразно; найденные отличия исправить теми же классами, без новых разновидностей.
- Стили только в css-файлах, существующими классами кнопок; новых цветов не вводить.

## Как проверить

Тест: у кнопок «Сохранить» и «Проверить» раздела «Модель» общий базовый класс кнопки. `npm run typecheck`, `npx vitest run --maxWorkers=2`, `npm run build`. В отчёте перечислить, какие кнопки были приведены к общему виду.

## Не делать

Не менять логику. Не трогать `src/core`, `src/main`, `src/renderer/pet`, `src/renderer/chat`.
