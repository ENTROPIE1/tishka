# 96. Речь начинается с задержкой: озвучка по предложениям и прогрев без помех

По журналу времени: ответ из 174 знаков синтезировался одним запросом 8,6 секунды, и только потом зазвучал. Короткий ответ из 20 знаков синтезировался 3,8 секунды вместо одной: одновременно со службой разговаривал прогрев готовых фраз (пять запросов разом), запущенный сохранением настроек.

## Что сделать

1. Озвучка по предложениям. Текст реплики после подготовки (`src/voice/speech-text.ts`) делится на части по границам предложений; слишком длинное предложение (больше 120 знаков) делится по запятой или точке с запятой. Первая часть уходит на синтез сразу и начинает звучать, как только готова; следующие синтезируются по очереди, пока звучит предыдущая (не больше одного запроса к службе на реплику одновременно, с опережением на одну часть). Между частями нет слышимой паузы длиннее обычной паузы между предложениями. Рот, состояние «говорит», остановка речи, вытеснение новой репликой и страховочный срок работают для реплики целиком: остановка обрывает звук и отменяет ещё не синтезированные части.
2. Ошибка синтеза одной части не обрывает остальные: часть пропускается, следующая звучит (поведение задачи 76 сохраняется).
3. Прогрев готовых фраз (`warm`) не мешает живой реплике: запросы прогрева идут по одному, а на время синтеза живой реплики прогрев приостанавливается. Сохранение настроек, не менявшее адрес службы синтеза и не включавшее озвучку, прогрев не запускает.
4. В журнал времени (`timing.log`) для каждой части пишется номер части и число частей; добавить отметку «первый звук реплики» с временем от показа ответа.

## Как проверить

Тесты: реплика из трёх предложений даёт три запроса по очереди, звук первой части начинается до окончания синтеза третьей; остановка во время первой части отменяет остальные; ошибка второй части не мешает третьей; прогрев не идёт одновременно с живой репликой; сохранение настроек без изменения синтеза не запускает прогрев. Сценарий в `tests/scenarios`: длинный ответ начинает звучать после синтеза первого предложения. `npm run typecheck`, `npm run test:scenarios`, `npx vitest run --maxWorkers=1` (проверки по одной, память машины ограничена), `npm run build`. Обновить `docs/contracts.md`.
