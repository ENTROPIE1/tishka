# 46. Вёрстка настроек: кнопки, раздел «Голос», мелкие недочёты

## Цель

Убрать недочёты вёрстки, найденные на снимке окна, и две мелочи поведения.

## Что сделать

### Кнопки (все экраны настроек и автоматизаций)

- Текст внутри кнопок сейчас рисуется с собственной серой подложкой — выглядит как выделенный текст. Причина — вложенный элемент подписи, который добавляет `runWithFeedback` (или общий стиль `span`/`label` внутри кнопки). Подпись кнопки не имеет своего фона, рамки и отступов; фон только у самой кнопки.
- Кнопки в одной строке (`.row`) стоят с промежутком 8 px и переносятся на новую строку с тем же промежутком по вертикали; соседние строки кнопок не слипаются (отступ между строками 8 px).
- Одна основная кнопка на раздел (цветная), остальные второстепенные.

### Раздел «Голос»

Раздел делится на три подписанные группы с подзаголовками:

1. **«Как звать Тишку»**: горячая клавиша, «Откликаться на имя», имена, «Уходить после тишины».
2. **«Микрофон»**: чувствительность и кнопка «Проверить микрофон» рядом с ней. Полоска уровня, подпись «слышу речь / тихо» и распознанный текст показываются только во время проверки и после неё; до первой проверки блок скрыт и места не занимает.
3. **«Служба распознавания»**: программа, модель, состояние и кнопка «Перезапустить службу» (бывшая «Проверить» — прежнее название не говорило, что именно проверяется). Состояние — небольшая метка по ширине текста с цветной точкой, а не полоса на всю ширину.

Кнопка «Сохранить» одна, внизу раздела, сохраняет все три группы. Сообщения об успехе и ошибках — под ней.

Флажок «Откликаться на имя» и флажок «Говорить вслух» в разделе речи: флажок слева, подпись справа в одной строке, пояснение под ними.

### Мелочи поведения

- Переключатель «Включён», правка и удаление навыка на экране «Автоматизации» не должны добавлять в ленту чата карточку «Навык сохранён». Карточка появляется только когда навык сохранён в диалоге с Тишкой. Для этого событие `skill.saved` получает необязательное поле `source: 'dialog' | 'screen'` (добавить в `docs/contracts.md`), карточку в чате и в окне-питомце вызывает только `'dialog'`.
- Раздел речи (`speech-section.ts`) возвращает `{ refresh() }` и перечитывается при показе экрана «Голос», как остальные разделы.
- Подготовка текста для речи: слова из словаря латиницы склоняются по контексту хотя бы для частого случая — после «и», «в», «из», «открой» слово «Jira» даёт «джиру» в винительном падеже («открой конфлюенс и джиру»), в остальных случаях «джира». Сделать таблицей форм для слов словаря, оканчивающихся на «а», и правилом: после глаголов из короткого списка (открой, проверь, посмотри, покажи, обнови, запусти) — винительный падеж.

## Как проверить

Тесты (jsdom):

- кнопка после `runWithFeedback` не содержит вложенных элементов с классами, задающими фон; текст кнопки меняется и возвращается;
- раздел «Голос»: три группы с подзаголовками, блок проверки микрофона скрыт до первой проверки, одна кнопка «Сохранить», кнопка «Перезапустить службу» вызывает проверку службы;
- сохранение навыка с экрана не добавляет карточку в ленту; сохранение из диалога добавляет;
- `prepareForSpeech('Открой Confluence и Jira')` → «Открой конфлюенс и джиру»; «Jira недоступна» → «джира недоступна».

`npm run typecheck`, `npx vitest run --maxWorkers=2`, `npm run build`.

## Не делать

Новые настройки, изменение логики распознавания и записи, правки окна-питомца.
