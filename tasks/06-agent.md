# 06. Агентный цикл

## Цель

Превращать фразу пользователя в действия и ответ: модель выбирает инструменты, цикл их выполняет, в конце получается `Reply`.

## Что сделать

`src/core/agent/agent.ts`

```ts
function createAgent(deps: {
  llm: { chat(req: ChatRequest): Promise<ChatResponse> };
  registry: ToolRegistry;
  events: EventBus;
  getModel: () => string;
  now: () => Date;
}): {
  handle(userText: string): Promise<Reply>;
  history(): ChatMessage[];
  reset(): void;
};
```

1. Цикл: отправить историю и список инструментов → если модель вернула вызовы инструментов, выполнить их через реестр и добавить результаты в историю → повторить. Не больше 8 кругов, затем вернуть ответ «не получилось, слишком много шагов».
2. Итоговый ответ модель отдаёт вызовом служебного инструмента `reply` с аргументами `say`, `show`, `mood`. Этот инструмент цикл добавляет к списку сам и не передаёт в реестр. Если модель ответила обычным текстом, текст превращается в `Reply`: первые два предложения в `say`, весь текст в `show` как панель `text`.
3. Системное сообщение в `src/core/agent/prompt.ts`. В нём:
   - кто такой Тишка и как он говорит (дружелюбно, коротко, на «ты», мужской род);
   - правило для `say`: до двух коротких предложений, без цифр, латиницы и сокращений — всё словами;
   - подробности, списки и ссылки идут в `show`;
   - сегодняшняя дата, время и день недели;
   - правило безопасности: ничего не отправлять и не менять без человека; письма и встречи только черновиком.
4. Результат инструмента в истории обрезается до 6000 символов с пометкой «обрезано».
5. История хранится в памяти, не больше 40 последних сообщений. Системное сообщение не вытесняется.
6. События: `think.start` перед каждым обращением к модели, `reply` с итоговым ответом, `error` при сбое. При `LlmError` возвращается `Reply` с понятной фразой и `mood: 'confused'`, исключение наружу не выходит.

## Как проверить

Тесты `tests/agent.test.ts` с подменой `llm` и реестра:

- Модель сразу вызывает `reply` → возвращается этот `Reply`, реестр не вызывался.
- Модель вызывает инструмент, потом `reply` → инструмент выполнен один раз, его результат попал в историю.
- Модель отвечает текстом → `say` не длиннее двух предложений, полный текст в `show`.
- Модель бесконечно вызывает инструменты → цикл останавливается на восьмом круге.
- Сбой инструмента (`ok: false`) попадает в историю как результат, цикл продолжается.
- `LlmError` → `Reply` с `mood: 'confused'` и событие `error`.
- Длинный результат инструмента обрезан.

## Не делать

Запуск навыков по фразе, мастер создания навыка, сохранение истории на диск.
