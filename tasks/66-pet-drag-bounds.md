# 66. Перетаскивание ежа: строка ввода растёт, слева окно уходит за экран

## Что не так

1. При каждом перемещении ежа строка ввода под ним становится шире и в итоге вылезает за экран.
2. Справа перемещение ограничено краем экрана, слева — нет: строка ввода, карточки и сам ёж уходят за левый край, а ёж появляется с другой стороны экрана.

## Что сделать

- Найти причину роста: размеры окна-питомца и его частей должны быть одинаковыми до и после любого числа перемещений (вероятные места: `src/main/pet-window.ts`, `src/pet/layout.ts`, пересчёт границ с учётом масштаба экрана и округления, `setBounds`/`setPosition` при перетаскивании). Перемещение меняет только положение, не размер.
- Ограничение положения с обеих сторон: всё видимое содержимое окна (ёж, строка ввода, карточка слева от ежа) остаётся в пределах рабочей области экрана, на котором находится ёж. Слева и справа — симметрично. Перескока на другую сторону экрана нет.
- Несколько мониторов и масштаб 125–150 %: границы берутся от того экрана, где сейчас окно; сохранённое положение, которое оказалось вне экранов (монитор отключили), при показе возвращается в пределы.
- Расчёт границ — чистая функция в `src/pet/layout.ts` с тестами.

## Как проверить

Тесты: сто перемещений подряд не меняют размер; положение левее и правее допустимого прижимается к краю; экран с отрицательной координатой начала (монитор слева от основного); масштаб 1,25 и 1,5; сохранённое положение вне экранов.

`npm run typecheck`, `npx vitest run --maxWorkers=2`, `npm run build`.

## Не делать

Не трогать `src/core`, `src/voice`, `src/renderer/chat`, `src/renderer/settings`, `src/main/index.ts`. Файлы не длиннее 200 строк. Стили только в css.
