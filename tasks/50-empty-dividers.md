# 50. Пустые разделители «Новый разговор»

## Цель

При каждом запуске приложения в ленту добавляется разделитель «Новый разговор», даже если после прошлого разделителя не было ни одной реплики. В ленте копятся пустые разделители подряд.

## Что сделать

- Разделитель не записывается, если последняя запись истории — уже разделитель (или история пуста). Правило одно для всех причин начала разговора: запуск, кнопка, 30 минут тишины. Контекст агента при этом очищается как раньше.
- При чтении истории подряд идущие разделители показываются как один (последний) — чтобы уже накопившиеся не засоряли ленту.
- Служебные записи (`from: 'system'`) разговор не открывают: разделитель перед ними и после них по-прежнему считается «пустым».

## Как проверить

Тесты: три запуска подряд без реплик — в истории не больше одного разделителя в конце; разделитель, реплика, новый разговор — второй разделитель записан; история с пятью разделителями подряд отдаётся с одним; системная запись между разделителями не мешает их схлопыванию.

`npm run typecheck`, `npx vitest run --maxWorkers=2`, `npm run build`.

## Не делать

Изменение поиска по истории, вида разделителя, правил длительности разговора.
