# 61. Разговор не закрывается по тишине после ошибки распознавания; после «Не расслышал» микрофон не оживает

Находки 1 и 3 из `tasks/reports/54-voice.md` (там же тесты).

## Что сделать

- `src/voice/wake-flow.ts`: после любой обработанной фразы — распознана, «Не расслышал», ошибка службы, фраза не по адресу — таймер ухода заводится заново. Во время ответа таймер, как и сейчас, не срабатывает. Предупреждение «скоро уйду» и уход по тишине работают после ошибок так же, как после обычных фраз.
- `src/main/pet-listen.ts`: исходы `nospeech` и `error` одиночной записи завершаются событием `idle`, как `cancel` (после события `error`).

## Как проверить

Тесты из отчёта (перенести в `tests/`), плюс: ошибка службы (не «Не расслышал») — режим закрывается по тишине; после ошибки предупреждение о скором уходе приходит в положенный срок; фраза во время ответа таймер не заводит раньше конца ответа.

`npm run typecheck`, `npx vitest run --maxWorkers=2`, `npm run build`.

## Не делать

Не трогать `src/core`, `src/renderer`, `src/main/pet-speak.ts`, `src/main/pet-wake.ts`, `src/main/chat-talk.ts`, `src/main/ipc-voice.ts`, `src/voice/stt-*.ts`. Файлы не длиннее 200 строк.
