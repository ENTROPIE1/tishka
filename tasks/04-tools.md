# 04. Реестр инструментов и встроенные инструменты

## Цель

Единый список инструментов, которым пользуются и агент, и исполнитель навыков. Первые встроенные инструменты.

## Что сделать

1. `src/core/tools/registry.ts` — реализация `ToolRegistry` из контрактов.
   - `register` с уже занятым именем заменяет инструмент.
   - `call` проверяет обязательные поля по `inputSchema.required`. Если поля нет, возвращает `{ ok: false, error }` с названием поля.
   - `call` никогда не бросает: исключение обработчика превращается в `{ ok: false, error }`.
   - До и после вызова отправляет в `EventBus` события `tool.start` и `tool.end`.
2. `src/core/tools/builtin.ts` — функция `registerBuiltinTools(registry, deps)`. Всё, что зависит от Electron, приходит в `deps`:

```ts
interface BuiltinDeps {
  openExternal(url: string): Promise<void>;
  showPanel(panel: Panel): void;
  now(): Date;
}
```

| Инструмент | Аргументы | Что делает | readOnly |
|---|---|---|---|
| `open_url` | `url: string` | Открывает ссылку в браузере по умолчанию. Разрешены только `http` и `https` | false |
| `open_urls` | `urls: string[]` | Открывает несколько ссылок по очереди | false |
| `show_panel` | `panel: Panel` | Показывает панель пользователю | true |
| `get_time` | — | Текущие дата и время в ISO и день недели по-русски | true |

3. Описания инструментов (`description`) на русском, одним предложением, с точки зрения пользы: модель по ним выбирает инструмент.

## Как проверить

Тесты `tests/tools.test.ts`:

- Зарегистрированный инструмент есть в `list()` и вызывается.
- Неизвестное имя → `{ ok: false }`.
- Нет обязательного поля → `{ ok: false }` с именем поля.
- Исключение обработчика → `{ ok: false }`, исключение наружу не выходит.
- События `tool.start` и `tool.end` приходят в правильном порядке, `ok` в `tool.end` верный.
- `open_url` со схемой `file:` или `javascript:` отклоняется и `openExternal` не вызывается.
- `unregisterSource` убирает только инструменты этого источника.

## Не делать

Скриншоты, напоминания, наблюдения, инструменты навыков — отдельные задачи.
