# 92. Остановка работы голосом и из окна ежа

Канал остановки текущей работы сделан в задаче 84. Добавить:

- Слова «стоп», «хватит», «остановись», «отмена» (с именем и без, отдельной короткой фразой), сказанные в разговоре, пока Тишка думает, работает или говорит, останавливают текущую работу и речь; в ядро как реплика не уходят. Ёж коротко показывает подписью «остановил» и остаётся слушать. Вне работы те же слова — обычная реплика.
- В строке ввода ежа, пока Тишка занят, кнопка отправки становится кнопкой остановки (тот же вид, что в чате основного окна); Escape в строке ежа делает то же.
- Сценарии в `tests/scenarios`: «стоп» во время работы останавливает и не уходит в ядро; «стоп» в покое уходит как реплика; кнопка остановки у ежа.

`npm run typecheck`, `npm run test:scenarios`, `npx vitest run --maxWorkers=1`, `npm run build`. Файл `wake-flow.ts` не увеличивать.
