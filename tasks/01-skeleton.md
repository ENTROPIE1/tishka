# 01. Каркас приложения

## Цель

Пустое приложение Electron на TypeScript, которое запускается, проверяется и тестируется одной командой. На него опираются все остальные задачи.

## Что сделать

1. Создать проект в каталоге `tishka/`: Electron, TypeScript в строгом режиме, сборка через `electron-vite`, тесты на `vitest`.
2. Создать структуру каталогов из `docs/contracts.md`. Пустые каталоги отметить файлом `.gitkeep`.
3. `src/core/types.ts` — перенести все типы из `docs/contracts.md` без изменений.
4. `src/core/events.ts` — реализация `EventBus`: `emit` вызывает всех подписчиков по очереди, исключение в одном подписчике не мешает остальным, `on` возвращает функцию отписки.
5. `src/main/index.ts` — главный процесс: создаёт одно обычное окно с надписью «Тишка» (временная заглушка) и экземпляр `EventBus`.
6. `src/main/preload.ts` и `src/main/ipc.ts` — мост между окнами и ядром: окно может подписаться на события (`onEvent`) и отправить текст пользователя (`sendUserText`). `contextIsolation` включён, `nodeIntegration` выключен.
7. Скрипты в `package.json`: `dev`, `build`, `typecheck`, `test`.
8. `.gitignore`: `node_modules`, `out`, `dist`, `*.log`.

## Зависимости

`electron`, `electron-vite`, `vite`, `typescript`, `vitest`. Других не добавлять.

## Как проверить

- `npm run typecheck` и `npm test` проходят.
- `npm run dev` открывает окно с надписью «Тишка».
- Тест `tests/events.test.ts`: подписчик получает событие; после отписки не получает; исключение в первом подписчике не мешает второму.

## Не делать

Прозрачное окно, чат, голос, обращение к модели — это другие задачи.
