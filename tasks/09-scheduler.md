# 09. Расписание: напоминания и запуск навыков по времени

## Цель

Тишка сам запускает навыки по времени и напоминает о делах. Расписание переживает перезапуск приложения.

## Что сделать

`src/core/triggers/cron.ts`

```ts
function parseCron(expr: string): CronSpec;                 // бросает Error с понятным текстом
function cronMatches(spec: CronSpec, date: Date): boolean;  // по местному времени, с точностью до минуты
```

Пять полей: минута, час, день месяца, месяц, день недели (0 и 7 — воскресенье). В поле допустимы `*`, число, список через запятую, диапазон `a-b`, шаг `*/n`. Другого синтаксиса нет. Сторонние библиотеки не использовать.

`src/core/triggers/state.ts`

```ts
interface Reminder { id: string; at: string; text: string; done: boolean }   // at — ISO
interface TriggerState {
  reminders: Reminder[];
  firedOnce: string[];                                  // id навыков с разовым запуском, которые уже сработали
  watches: Record<string, { last?: string; errors: number }>;   // заполняет задача 10
}
function createTriggerState(filePath: string): {
  load(): Promise<TriggerState>;      // нет файла или он повреждён → пустое состояние
  save(state: TriggerState): Promise<void>;   // атомарно: временный файл и переименование
  exclusive<T>(task: () => Promise<T>): Promise<T>;   // общая очередь: задачи выполняются строго по одной
};
```

Файл `triggers.json` лежит в каталоге данных пользователя. С ним работают и расписание, и наблюдения, поэтому каждая последовательность «прочитать, изменить, записать» выполняется внутри `exclusive`: так один модуль не затирает изменения другого.

`src/core/triggers/scheduler.ts`

```ts
function createScheduler(deps: {
  skills: { list(): Promise<Skill[]> };
  runner: { run(skill: Skill, inputs?: Record<string, unknown>): Promise<RunResult> };
  state: ReturnType<typeof createTriggerState>;
  events: EventBus;
  now: () => Date;
}): {
  start(): Promise<void>;       // читает состояние, отрабатывает пропущенное, запускает проверку раз в 20 секунд
  stop(): void;
  tick(): Promise<void>;        // одна проверка; вызывается таймером и из тестов
  addReminder(at: string, text: string): Promise<Reminder>;
  listReminders(): Promise<Reminder[]>;
  removeReminder(id: string): Promise<void>;
};
```

1. Напоминание срабатывает, когда `now >= at`: событие `wake` с `source: 'trigger'`, событие `notify` с текстом в `title`, событие `reply` с `say`, равным тексту напоминания. После этого `done: true`.
2. Навык с `trigger.type === 'schedule'` и полем `at` запускается один раз, его `id` попадает в `firedOnce`.
3. Навык с полем `cron` запускается, когда `cronMatches` верно для текущей минуты. В одну и ту же минуту навык запускается не больше одного раза.
4. Перед запуском навыка отправляется `wake` с `source: 'trigger'`, после успешного — `notify` с названием навыка и `skillId`.
5. Пропущенное за время, когда приложение было закрыто: напоминания и разовые запуски, опоздавшие не больше чем на 12 часов, срабатывают при `start()`. Более старые помечаются выполненными без срабатывания. Запуски по `cron` не догоняются.
6. Сбой навыка не останавливает расписание: событие `error`, проверка продолжается.
7. Список навыков перечитывается на каждой проверке.

`src/core/triggers/tools.ts` — `registerTriggerTools(registry, scheduler, now)`:

| Инструмент | Аргументы | Что делает | readOnly |
|---|---|---|---|
| `create_reminder` | `time: string`, `text: string` | Создаёт напоминание. `time` — ISO или `ЧЧ:ММ`; для `ЧЧ:ММ` берётся сегодня, а если время уже прошло — завтра | false |
| `list_reminders` | — | Список невыполненных напоминаний | true |
| `delete_reminder` | `id: string` | Удаляет напоминание | false |

Описания инструментов на русском, одним предложением.

## Как проверить

Тесты `tests/cron.test.ts`, `tests/scheduler.test.ts`, время подменяется через `now`:

- `parseCron`: `*/15 9-18 * * 1-5` совпадает в понедельник 09:30 и не совпадает в субботу; `0 9 * * 5` совпадает только в пятницу 09:00; неверное выражение даёт ошибку.
- Напоминание не срабатывает раньше времени, срабатывает один раз, события идут в порядке `wake`, `notify`, `reply`.
- Состояние переживает перезапуск: новый планировщик на том же файле видит напоминание.
- Навык с `cron` за одну минуту запускается один раз даже при трёх проверках подряд.
- Разовый навык после срабатывания не запускается снова.
- Пропущенное на 1 час срабатывает при `start()`, пропущенное на 20 часов — нет.
- Сбой навыка даёт событие `error`, следующая проверка работает.
- `create_reminder` с `ЧЧ:ММ` в прошлом создаёт напоминание на завтра.

## Не делать

Наблюдения, окно со списком напоминаний, повторяющиеся напоминания.
