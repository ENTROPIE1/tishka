# 91. Белое окно после перезапуска и осиротевший процесс в режиме разработки

1. В режиме `npm run dev` приложение, перезапустившееся само (сторож памяти, `app.relaunch()` в `src/main/index.ts`) или оставшееся в области уведомлений после закрытия терминала, теряет сервер разработки: страницы не загружаются, окно белое или без стилей. Сделать: при неудачной загрузке страницы с адреса сервера разработки (событие `did-fail-load`) окно загружает собранные страницы с диска, если они есть, иначе показывает понятную страницу-сообщение «Сервер разработки недоступен. Закройте Тишку и запустите npm run dev заново». В режиме разработки автоматический перезапуск по памяти не делать: вместо него запись в журнал времени и сообщение человеку.
2. Перезапуск по пределу памяти в собранном приложении: убедиться тестом, что после перезапуска окна загружаются с диска и ёж появляется по обычным правилам запуска.
3. Нестабильный тест `tests/memory-prompt.test.ts` (иногда падает в полном прогоне: гонка очистки временного каталога). Перевести на общий помощник временных каталогов `tests/core-helpers.ts`, как остальные тесты.

`npm run typecheck`, `npx vitest run --maxWorkers=1` три раза подряд без падений, `npm run build`. Не трогать окно ежа сверх загрузки страницы, разговор и запись.
