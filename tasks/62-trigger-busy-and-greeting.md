# 62. После напоминания Тишка не откликается на имя; на уведомление звучит «Слушаю»

Находки 2 и 4 из `tasks/reports/54-voice.md` (там же тесты).

## Что сделать

- После реплики, пришедшей не в ответ на просьбу пользователя (напоминание, навык по расписанию, наблюдение за страницей, обзор памяти), ядро отправляет событие `idle` — так же, как после обычного ответа. Найти все такие места в `src/core` (`triggers/`, `memory/review.ts` и другие, где отправляется `reply` вне `processUserText`) и сделать одним общим способом.
- `src/main/pet-speak.ts`: приветствие «Слушаю» при событии `wake` с источником `trigger` не произносится; сам текст уведомления произносится.

## Как проверить

Тесты из отчёта (перенести в `tests/`), плюс: после напоминания при выключенном синтезе прослушивание имени снова активно; при включённом синтезе звучит только текст напоминания; после каждого из найденных мест приходит `idle`.

`npm run typecheck`, `npx vitest run --maxWorkers=2`, `npm run build`.

## Не делать

Не трогать `src/renderer`, `src/voice/wake-flow.ts`, `src/main/pet-listen.ts`, `src/main/ipc-voice.ts`, `src/core/skills/validate.ts`, `src/core/mcp`. Файлы не длиннее 200 строк.
