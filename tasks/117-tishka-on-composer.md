# 117. Тишка стоит на строке ввода, а не висит в воздухе

После задачи 115 холст шире и клики по кнопкам работают, но новый Тишка визуально висит над строкой: ступни не стоят на рамке ввода.

## Причина (проверено чтением)

- `PET_TISHKA_STAND` = перевод пустоты модели под ступнями (1220 − 1184 = 36 единиц → 8 точек). Холст опускается на 8 точек ниже рамки персонажа — этого мало, чтобы дойти до строки ввода.
- Рамка `.character.rig` имеет `margin-bottom: calc(-1 * var(--pet-label))` — наезд только на подпись состояния (18 точек), не на строку.
- `.composer-host { width: calc(100% - var(--pet-feet)) }` укорачивает всю строку, справа дыра. Ступни висят над пустым прозрачным окном, а не рисуются поверх рамки строки. Задача 115 требовала оба условия сразу: строка короче на ширину ног **и** ноги лежат на рамке.

Строка — сосед снизу (`.composer-host` после `.pet-row` в `index.html`), высота около 48 точек (поля 8+10 и кнопки 30).

## Что сделать

- Константа посадки: `PET_TISHKA_STAND` (или отдельная, рядом в `character-size.ts`) должна опускать холст так, чтобы низ ступней (`TISHKA_FEET_BOTTOM`) лёг на верхнюю половину рамки строки ввода (наезд порядка высоты строки, не 8 точек). Рамка `.character` тоже опускается на этот наезд, подпись состояния остаётся над строкой и не перекрывает поле.
- Строка ввода **на всю ширину окна** (`.composer-host` не урезать на `--pet-feet`). Кнопки и поле уводятся из-под ступней внутренним полем строки (`padding` на `--pet-feet`), как уже сделано. Персонаж рисуется поверх рамки (`z-index` холста выше строки). В зеркальной раскладке — то же с другой стороны.
- Прежний ёж без изменений: `stand` и `feet` ноль, строка полной ширины.
- Клики: прозрачные пиксели холста над строкой по-прежнему проходят к полю и кнопкам (`isInteractiveTarget` не ломать). Непрозрачные ступни — перетаскивание.

Файлы: `src/pet/character-size.ts`, `src/renderer/pet/pet.css`, `src/renderer/pet/composer.css`, тесты `tests/pet-character-figure.test.ts` / `tests/pet-figure-geometry.test.ts`. При необходимости сценарий в `tests/scenarios/`.

## Как проверить

- `PET_TISHKA_STAND` заметно больше 8 точек и не меньше высоты строки ввода (поля + кнопка).
- В CSS нет `width: calc(100% - var(--pet-feet))` у `.composer-host`; есть внутреннее поле строки на `--pet-feet`.
- Холст и рамка `.character.rig` опускаются на `--pet-stand` / посадку; подпись не накрывает поле.
- Прежний ёж: раскладка и размеры как до 115.
- `npm run typecheck`, `npm run test:scenarios`, `npx vitest run --maxWorkers=1`, `npm run build`.
